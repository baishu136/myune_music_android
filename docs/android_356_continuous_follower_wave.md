# Android 356：严格 6.5% 位移与全语种三阶连续跟随

日期：2026-10-04。版本：`1.0.0+356`，Android 显示 `1.0.0-android.356`。

## 本轮范围与基线

以实际工作区 355 为基线，保留此前未提交的 354 桌面歌词修复及 355 的字形、退出和布局成果，不重置无关改动。355 APK、源码和留档仍保留，可供完整回退；生产代码只维护新默认模型。

355 的位移按排版行高乘 0.27 后限幅 2–14px，还包含中文快字减幅、独立跟随延迟、四阶叠加包络。连接条件只允许同类拉丁字母或汉字，假名及跨语种混排无法形成跟随链。本轮按最新需求替换这些规则，不更改真实高亮时间、播放时钟、三种滚动模式、翻译高亮规则或公开设置。

## 默认模型

- `liftHeightFraction` 严格为 `0.065`，配置拒绝其他数值。最大位移 = `textScaler.scale(fontSize) * 0.065`，不按行高，不设 2px 下限或 14px 上限，不按语言或速度减幅。40px 字号、不额外系统缩放时为 2.6 个逻辑像素；屏幕像素还取决于 DPR。
- 未唱 `dy = maxLift`；上浮到位 `dy = 0` 并永久保持。保留既有行退出包络，未完成的残余下沉在正常退场期间向上收拢；已唱字不下落。
- 自主上浮从字符扫光进入开始，采用 smoothTop 曲线，默认上限 240ms，配置允许 220–260ms。实际时长为 `min(240ms, 自身扫光窗口)`，确保扫光完成后已经到位。快字窗口短于 220ms 时不延长高亮或伪造真实时间；长拖音提前到位后保持。
- 所有自主时间使用媒体时间，2x 时 240ms 媒体时间对应 120ms 实际时间。暂停、恢复、倍率与 Seek 沿用统一媒体时钟；同一媒体时间不依赖历史帧。
- 默认三阶 `followerWeights = [0.65, 0.35, 0.15]`；结果严格为本字自主进度与最多三个前驱自主进度乘相应权重的最大值，不使用延迟、乘积叠加或递归传播。
- 原始词元边界、已有视觉补偿与词元内部字素估算保持区分。普通 LRC 的运动锚点根据既有连续扫光路径在布局时反求，是合成估算，不宣称实测逐字时间。

## 实际绘制接入与兼容

`mobile_lyrics_list.dart` 的静态占位/翻译留白和 `karaoke_paint_cache.dart` 的实际逐字绘制统一使用缩放后的字号，而非 `TextPainter.preferredLineHeight`。列表 item 高度与滚动目标不随逐字开关改变。

连接不再检查脚本种类：英文、汉字、假名、带组合符号的完整字素以及混排均走同一运动管线。空白、真实停顿、物理折行和方向变化继续断链，避免波浪带起远处整行。连字、Emoji、复杂原生字形仍作为完整安全绘制单元，不为逐字位移破坏文字塑形；这些运行内部不强拆成独立字母。

加入扫光时间轴区间只读接口，将布局阶段反求限制到当前物理行的时间区间。0% 相位在起唱前始终为零，不能直接从整句起点反求，否则后续折行首字会提前运动；测试覆盖了该边界。

前驱关系、运动锚点及 typed buffers 在缓存阶段建立。每个绘制帧先把自主进度写入复用的 `Float64List`，然后读取三个前驱的标量；不创建逐帧 Map/List，不重复计算每个前驱曲线，不新增逐帧排版或字形蒙版。保留有界图集、预热、墨迹完整归属与透明度合成。

严格 max 组合保证位移连续、单调且有界，但在自主/跟随分支交接时不保证数学上的一阶导数连续；不额外平滑公式改变用户指定权重。不能将测试采样连续等同于真机满帧或 Salt Player 观感实测。
