# Android 289：逐字歌词位移与跳转时钟

日期：2026-09-14

## 修复

- 将上一版过小的行位移改为可辨识幅度：离场行向上移动行高 16%，候场行从下方 22% 处归位。
- 位移动画独立使用 520 毫秒节奏，不再被 620 毫秒的整表滚动视觉抵消。
- 逐字视觉时钟记录相邻播放位置与实际经过时间，识别点击歌词、拖动进度和解码器时间轴跳变。
- 跳转发生时立即重锚到目标时间，不再从旧单词位置平滑追赶，避免高亮回拉与短暂停顿。

## 性能

- 行位移继续由 `AnimatedSlide` 在合成阶段完成，不增加布局、文字测量或逐帧 Widget 重建。
- 连续性判断只在播放位置通知到达时执行固定数量的整数运算。
- 正常播放的小幅进度抖动仍由现有视觉时钟平滑吸收。

## 验证

- 覆盖正常播放回调、向前跳转和向后跳转的连续性判断。
- 覆盖行位移的方向、幅度、时长、缓动曲线和安全绘制范围。
- 执行静态分析、完整 Flutter 测试与 arm64 release 构建。
