Myune Music 1.0.0 / Android 412，汇总上次 Android 387 Release 之后的有效改动。应用内历史日志按实际 GitHub Release 归并，保留每个发布版本的一条记录。

## 新功能

- 播放页选歌列表提供加入播放队列和下一首播放按钮，自定义均衡器可命名保存预设，并在高级设置中管理。
- 新增固定首位的“总歌曲”歌单，与音乐库共用管理；仅该歌单提供导入入口，导入不再自动收藏。
- 新增“循环播放，随机切歌”模式，当前歌曲循环、手动切歌随机；可按收听次数及中、英、日文标题设置跳过规则。
- 长按上一曲或下一曲可每0.6秒连续切歌，松手停止；长按收藏或播放模式半秒打开对应面板。
- 收藏改为放大淡入的悬浮歌单窗，显示封面、数量和创建日期；左侧圆形选择按钮支持即时加入或移出当前歌曲。
- 桌面歌词新增逐行自动缩小、独立逐字高亮及颜色设置，以及左对齐、居中和右对齐。
- 歌词源可在未匹配歌词或真实逐字时自动补查其他平台，按网易、QQ、酷狗顺序且跳过已选源；全部模式可为普通歌词估算逐字。
- 歌曲详情支持长按复制带下划线的信息，成功后轻微震动并在底部提示。

## 修复

- 修复普通网络歌词误入真实逐字模式，以及正常匹配后反复刷新词源导致状态重置的问题。
- 修复普通歌词滚动启动、落位及连续短句的缓存缺口，减少微小回退、切页位移和重复绘制。
- 统一多歌手识别与分隔符处理，歌手歌曲列表包含参与合唱的歌曲，不再因大小写和空格差异遗漏。
- 移出歌单时保护总歌曲、其他歌单和当前播放队列；保存失败可重试，取消最后一首歌曲后及时清除旧封面。
- 动态背景采用柔和扩散混色，减少大块色斑与突兀明暗边界。

## 优化

- 切歌与恢复播放使用短暂高频柔化，平缓恢复音色，保留用户音量和均衡器参数。
- 动态背景四个色团使用6～8种封面相关颜色，扩大游走范围，以长距离线性加减速和柔和中间色衔接切歌。
- 封面白色外光采用20%不透明度，等待播放页完整入场后渐亮，切歌时保持原有光晕。
- 普通歌词非正播行随距离从最高40%降至最低15%不透明度；弹性模式采用整行错峰回弹，原文折行与译文一起运动。
- 歌词绘制、模糊和高亮共用帧时钟，正文与光晕有限预热并复用缓存，减少换行时的集中准备开销。
- 连续切歌期间暂缓歌词和背景准备，只保持播放及封面、标题更新；底部选歌控件记住上次页面和列表位置。
- 播放模式从底部弹出，封面与收藏等功能面板统一透明风格；顶部控件切页加入淡入淡出。
- 应用内更新日志按实际GitHub Release归并，每个发布版本保留一条，补齐历史发布并按最终有效行为去重。
