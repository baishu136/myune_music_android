# Android 381：背景衔接、全屏提示和歌曲管理

日期：2026-10-12（Asia/Shanghai）。用户要求改善封面/动态背景大色差切歌衔接、增强动态背景色彩区分与运动范围，改成36字号无封面的全屏切歌提示，自动重排变化的歌曲列表，调整全选位置，修复隐藏歌曲并增加文件夹管理。

## 背景

- 封面保持同一原生高斯路径、镜像原图和屏幕外支持；大色差淡入上限900→1400ms、近色约280ms，曲线改用五次平滑函数，端点速度与加速度均归零。16×16颜色采样复用、最多两图绘制和一个最新待切目标保持。快速连续换图仍先完成当前交接再处理最新目标；最大约两段/2.8秒，另加解码/采样等待，不宣称瞬时跟上最后一首。
- 动态配色由固定650ms改为按当前显示色与目标色的预乘RGB跨度选择650–1400ms；继续从当前显示palette重定向，轨道时间不重启，曲线与uniform插值同源。只在换曲计算时长，29-float ABI、帧缓存/差量写入、实际VSync调度、退场冻结和质量/前后台/FFT保护保持。
- 四团轨道基础半径.33→.39，谐波.11/.06→.16/.09，理论径向区间.14–.64；中心漂移x±.065→±.085、y±.055→±.075。各团可部分离开屏幕，保留不规则变速/变色与41.89秒连续周期。宽衔接尺度.44保持，归一化凸混色规则保持。
- 团间颜色借入量约减半；颜料覆盖.66–.82→.74–.92，增加实际色域区分，不凭空增加彩虹色相，也不把灰黑封面染彩。合成同一诊断网格平均HSL饱和度约.3662→.3999，仅说明该样本，不是所有封面必然提升相同幅度。
- 136张实际shader软件样本（120帧/12秒10Hz、16份四色全周期静帧）及20帧接触表已查看。横竖32相位四个主要色域保持连通并触边；第四团亮度质心半径约.272–.502，原379约.290–.468。96×160空间RGB步长5、24Hz时间步长3、导出10Hz步长4，均是软件样本而非真机GPU数据。

## 全屏歌词切歌提示

- 不再显示封面；标题和歌手两行均固定36逻辑字号，不跟系统文字缩放；超长内容单行省略。安全区顶部及手机16/平板28左右边距保持，最大宽420。
- 只在实际横滑切歌完成且当前歌曲身份变化后显示；失败、取消、同曲重播及其他入口切歌不误触发。已显示提示随有效切歌退出：下一首向左、上一首向右，110ms，与歌词交接一致；新文字分别从右/左20dp入场、220ms缓出。
- 事件后停留2200ms，提示统一在140ms内向右64dp并淡出。新事件重新计时并使用新的入场/交接；退出全屏/切封面/路由/后台清除，重新进入不重放。减少动画直接显隐。稳定歌词层、IgnorePointer、独立浮层State与RepaintBoundary保持，无封面请求或第二套歌词。
- 六张MiSans软件预览已查看：浅/深、窄屏双倍系统字号、横屏，以及向右退场/从左入场的中间帧。为组件预览，静态示例歌词，不代表完整播放器真机截图。

## 排序、全选与隐藏

- 文件路径和排序相关元数据进入顺序签名；新增/删除、标签/时长变更重新应用已有规则，无规则时使用标题升序，置顶仍优先。元数据变更300ms合并后等待空闲，后台拼音worker保持；下游工作申请自己的空闲lease，不嵌套持有串行lease。防止异步排序结果覆盖更新过的成员集合，按歌曲身份更新播放索引，重排不会主动切换当前歌曲。库排序对话框读取乐库自己的规则。
- 乐库和歌单正常/多选状态均在顶栏最右提供全选，乐库按当前过滤结果选取。歌手/专辑歌曲页增加全选及多选收藏/隐藏/退出，详情直接读取当前分组，不保留初次入页的过期歌曲列表。歌单选择视图增加选择集合内容签名，修复同一个Set原地变更漏掉Checkbox重建。
- 隐藏原先使用`.where(set.add).isNotEmpty`懒求值，可能只处理第一个新增条目；改成完整遍历所有路径与去重身份。隐藏最后一批时，原路径集合并未为空，因此禁止从旧顺序文件恢复；确实清空过的曲库也不恢复旧列表。缓存保留原来源中的隐藏歌曲元数据，未知标签路径同样过滤。
- 乐库更多菜单与批量操作明确“隐藏歌曲”。隐藏后默认关闭隐藏项显示；有隐藏记录时右上角出现显示/隐藏按钮，可随时查看隐藏项，开关不删除持久隐藏记录。只改变列表可见性，歌曲文件与原歌单关系保留，重新启动默认隐藏；明确重新导入仍可恢复，普通文件夹刷新不撤销隐藏。

## 文件夹管理

- 设置→高级新增“歌单文件夹管理”，每个目录显示关联歌单、刷新和移除。单目录扫描仅更新明确关联的歌单，递归处理支持格式、不跟随链接；不可访问/扫描失败时不使用空扫描结果删除原列表。空目录和全隐藏目录仍能刷新，保留隐藏状态。
- 普通歌单“导入整个文件夹”也记录来源关联。旧版只有目录历史、缺少所属歌单的记录，首次刷新时选择目标歌单再建立关联，避免把整目录自动加入收藏或其他手动歌单。取消选择不执行刷新。
- 移除解除目录及对应歌曲引用；其他目录、重叠目录仍管理的歌曲和其他歌单保持；最后一个来源移除后保留为空/普通歌单。移除确认明确磁盘文件保留，不进行物理删除。刷新/移除/关联在访问持久记录前设置忙状态，避免多个入口并发处理同一列表。
- 移除的是明确绑定的来源引用；过去只留下历史且未绑定的目录，直接移除只清理历史记录。文件夹手工添加/移除与后续扫描属于来源同步行为，手动同路径引用未单独维护来源账本。
