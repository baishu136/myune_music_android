# Android 265：播放页封面与歌词边缘过渡

日期：2026-09-12

## 封面短暂模糊

- 原播放页封面即使已有高分辨率预解码结果，仍会经过渐进式图片组件；在图片缓存状态变化或 Hero 结束的交界帧，低分辨率预览可能短暂重新露出。
- 本版在预解码结果可用时直接复用完全一致的 `CoverMemoryImage` 缓存键，不再叠加 192 像素预览或执行二次淡入。
- 进入播放页前只有确实完成高分辨率解码且仍在图片缓存中的封面才参与 Hero；少数尚未准备完成的封面继续使用异步渐进加载，不阻塞页面进入。

## 歌词上下淡出

- 顶部淡出范围由最多 112 像素扩展至最多 200 像素，底部由最多 128 像素扩展至最多 224 像素，并随可用高度自适应。
- 上下边缘均使用透明、低透明度、中透明度、接近不透明和完全不透明的连续多段渐变，避免形成明显遮罩边界。
- 仅调整现有单个 `ShaderMask` 的常量和停止点，不新增模糊层、动画控制器或逐帧计算。
