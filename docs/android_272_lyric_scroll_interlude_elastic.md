# 0.9.9-android.272

## 大跨度歌词滚动

- 自动跟随遇到时间跳转、解码追赶或连续空行时，不再从旧位置逐行穿越全部离屏内容。
- 先无动画定位到目标附近，再只对最后 42% 视口范围执行原有连续滚动，减少中间 Sliver 的构建、布局和绘制峰值。
- 普通相邻歌词仍从当前位置连续滚动，原有 620 毫秒默认节奏不变。

## 间奏等待动画

- 三点等待提示进入时以 340 毫秒淡入并轻微上移。
- 离开间奏时以 280 毫秒柔和淡出，退出完成后才停止呼吸动画并清理进度。
- 非当前间奏不运行呼吸或进度 Ticker。

## 弹性滚动

- 最大视觉位移由视口高度的 28% 提升至 36%，上下限由 56–120 调整为 72–156 像素。
- 当前行立即回弹，相邻行按距离延后 10–44 毫秒，形成更清晰的逐行弹性波。
- 提高弹簧刚度并降低阻尼比，使起步更利落、过冲更明显，同时继续限制参与动画的缓存行范围。
