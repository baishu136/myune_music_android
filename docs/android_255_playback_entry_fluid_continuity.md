# Android 255：播放页入场与流体背景连续性

日期：2026-09-11

## 改动

- 播放页入场动画总时长由 520 毫秒延长至 700 毫秒，保留原有 Cupertino 位移动画和封面 Hero。
- 页面在动画触发时为 40% 不透明度，在总进度 80% 时达到 100%，最后 20% 只完成位置缓和，不再改变透明度。
- 流体背景按封面内容和缓存代际保存最近显示色板及运动相位；退出后再次进入同一首歌时从上一视觉状态继续，不回到主题备用色和零相位。
- 复用全局 64 项色板缓存以及已经加载的 FragmentProgram。重入不重新解析封面颜色，也不在路由结束后突然替换色板。
- 切歌时仍保留正常的色板渐变，并将旧歌视觉状态按各自键值保存，避免连续性优化污染其他歌曲。

## 性能策略

- 700 毫秒动画期间继续暂停歌词实时效果和流体运动，避免延长动画后同步延长高负载绘制。
- 动画结束后才恢复后台色板准备和局部毛玻璃；封面解码流程保持独立，不等待色板提取。
- 流体快照上限为 32 项，色板缓存上限仍为 64 项，避免长期使用时无界增长。
