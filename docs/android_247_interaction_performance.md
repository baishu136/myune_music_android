# 0.9.9-android.247 交互性能优化

## 优化

- 合并重叠交互窗口的截止时间，避免滚动结束的短窗口覆盖播放页进出转场窗口，导致非紧急任务提前启动。可见封面原有即时请求不变。
- 可见列表封面已解码或正在解码时不再反复预取，异步结果返回后再次检查图片缓存，避免同一封面重复挂接 precache 监听。
- 预取只响应当前纵向列表的滚动，不响应嵌套列表或横向滚动通知。
- 在主页内容与背景间、渐隐遮罩与列表间隔离重绘；不额外为 PageView 子页重复添加默认已有的绘制边界。
- 保持图片清晰度、动画时长、功能及组件加载入口不变。新增绘制边界可能增加少量图层/栅格缓存占用；无无限增长的新缓存。

## 验证范围

- 180 项 Flutter 测试通过，包括短滚动不能提前解除转场保护的回归测试。
- 当前无连接的 Android 真机，未取得帧耗时或内存峰值对比，不能保证所有设备无慢帧。
- 真机建议测试播放页连续进出、跨主页来回切换、封面列表快速滑动、切歌和自定义模糊背景组合，观察图片加载、交互响应、慢帧率与内存峰值。
