# Android 378：四个游走色团与更宽衔接

2026-10-10（Asia/Shanghai），`1.0.0+378`，正式ARM64 versionCode2378。

## 实现

用户要求动态背景扩展为四个色团，位置不固定，围绕中心但可以离开中心，并加宽色团边缘衔接。377的三个色团基础角间距120°、半径.205–.315，径向活动较小。378改为四场、基础角间距90°，各自有不同相位的角度与径向谐波；轨道中心本身缓慢漂移。

- 原始轨道半径在.16–.50归一化单位之间变化，纵向系数1.08；中心另有x±.065、y±.055游走，色团可向内收拢、向外接近边缘，部分中心可短暂越出屏幕。不会把色团钉在四个角或只绕固定的小圆。
- 角度扰动由.14增至.18，并保留公共连续变速相位及每团独立扰动。41.89秒周期、整数谐波回绕、实例随机初相位及快照续接保持；这是平滑周期伪随机，不是逐帧随机数。
- 颜色场衰减尺度由.32扩至.44，衰减由三次有理式变成二次，边缘尾部更宽、更柔和。四场仍按非负归一化权重凸混合，覆盖.66–.82；不是四层不透明大色团互相覆盖，也没有Screen加光。
- 已有palette.first从元数据改为第四个实际颜料，另三团仍取second/third/fourth。沿用现有封面取色，不生成新的彩虹色相。简单/单色封面可以重复颜色，因此四个运动场不保证四种可区分色相。第四团缓慢借入主色2%–10%，其他团保持3%–13%，全程连续混色。
- 48-float uniform ABI、650ms切歌配色、质量调度、FFT平滑、后台/减少动画/路由保护、单次shader绘制保持。封面280–900ms自适应淡入、原生高斯、歌词7%上浮及启动旧样本过滤、主页和歌曲选择代码与377逐文件相同。
