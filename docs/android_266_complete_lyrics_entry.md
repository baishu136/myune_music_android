# Android 266：歌词页完整入场动画

日期：2026-09-12

## 问题原因

- 歌词层在切回封面页后会保留，以避免重复创建完整歌词列表。
- 若歌词自动滚动或前一次封面、歌词切换尚未完全结束，滚动 ticker 和视觉控制器可能停留在中间进度。
- 再次进入歌词页时，旧实现会根据剩余进度缩短动画时长，因此只能看到后半段动画。

## 修复方式

- 点击进入歌词页时立即取消上一次切换遗留的延时任务，并停止封面及歌词视觉控制器。
- 在歌词完全透明的阶段重新定位当前播放行，同时清除尚未完成的自动滚动位移。
- 建立一帧确定的封面完整显示、歌词完全隐藏状态后，再从 0 到 1 播放完整切换动画。
- 歌词实时刷新仍在视觉入场结束后恢复，避免播放行变化与入场动画争用同一帧。

## 性能影响

- 没有新增动画控制器、渲染层或图片解码。
- 复用现有歌词列表和现有控制器，只在用户点击切页时执行一次状态归零与定位。
