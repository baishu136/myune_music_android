# Android388：队列操作、均衡器预设与歌词稳定性

日期：2026-10-14；版本1.0.0+388。基线为已发布387后的main提交`5a1f1f23251b57a9d38117eaa45c7d043dadae6d`，不是未发布的旧3665d5a。本轮未提交、推送、创建标签或Release，沿用无真机测试要求。

## 实现

- 播放页底部歌曲选择列表的乐库、歌手、专辑、搜索及歌单范围，歌曲末端统一使用加入播放队列、下一首播放两个图标，不显示时长。操作写入期间两个按钮禁用，失败提示且恢复；队列更改后更新抽屉源快照，避免关闭抽屉恢复旧源而丢失新增项。当前正播歌加入下一首时保留当前项，另插入一次供重播，不越界删除当前项。
- AudioService普通加载和两曲无缝加载先以暂停状态打开，准备AO的−60dB独立增益，再按实际`core-idle`反向的playing流推进480ms半余弦幅度曲线至0dB。缓冲冻结计时，恢复续接，主动恢复播放重新淡入；原生无缝换曲在playlist事件中触发淡入。写入串行并合并最新目标，旧曲、旧暂停回执与销毁不能覆盖新曲增益。不更改用户音量、睡眠计时音量、均衡器或响度参数，不添加AF节点。可选volume-gain失败时尝试回到0dB并停止重试。
- 自定义均衡器底部仅在确实手动改变频段之后显示“保留均衡器参数”，拖动中不显示；命名后保存十段参数，加入现有预设选择列表，重启仍保留。高级设置新增“均衡器参数”管理页，可移除自存预设；移除正在使用的预设保留当前增益并转为自定义。内置预设不能移除，同名、空名、超过40字和非法参数拒绝。没有新增解释副标题或附注。
- 三个平台网络结果携带禁止合成逐字的来源标记，普通LRC在timedOnly和ALL下均不估算词时间；真实YRC/QRC/KRC仍按返回时间。逐行判断，混合内容中普通行保留整行高亮，本地显式ALL估算功能保持。仅空白/零时长或非法起止时间不作为可用词时间；真实乱序时间保持，避免用估算覆盖原值。
- 相同歌词内容再次返回保留原列表与对象；同曲刷新期间保持可见歌词，不先清空并发布−1索引。只有初次换曲空列表才等待真实播放位置定行。普通网络歌词不再预热逐字字形；真实逐字仍复用共享时钟、字形缓存、既有预热、7%上浮和弹性行轨迹，未加入额外逐帧Provider刷新。
- 非逐字歌词：正播行100%，其他行距离1/2/3/4/5及更远分别40%/32%/25%/20%/15%，alpha只作用一次；浏览候选保留色相但不突破非正播上限。切行仍保留既有620ms焦点交接，避免突变；新目标参数不意味着退场过渡瞬时截断到40%。
- 白色窄范围外光最终alpha20%，blur10、spread0、outer保持。路由、封面transform、最新图像解码与交接全部完成后，仍720ms缓缓亮起，局部更新且不重挂封面。
