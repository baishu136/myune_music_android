# Android 382：标题淡入、系统导航、多选和动态取色

日期：2026-10-12，版本1.0.0+382，正式ARM64 versionCode2382。

## 界面和选择操作

- 全屏横滑成功切歌后的歌名/歌手均固定24，不随系统字号缩放，无封面；220ms easeInOutCubic淡入，保留左右入场、2200ms停留和140ms向右快速淡出。再切歌时从当前位移继续退出，避免尚未淡入完成就换方向引起跳位。失败/取消/同曲、生命周期与减少动画规则保持。
- Android启动显式使用edgeToEdge，应用外层底部AnnotatedRegion设置透明导航栏/分隔线并关闭contrast enforcement。主页将导航栏底色延伸至SafeArea底部，控制仍在系统按钮上方；Mini Player不叠加第二层填色。AppBar继续管理各页状态栏。未修改原生代码。
- 歌单“添加歌曲”文字/前景显式alpha=1，背景保持原填色。
- 主页乐库/歌单的普通入口改为“多选”，进入不自动全选。多选顶部按顺序仅全选、取消全选、取消多选、隐藏歌曲或取消隐藏；空选时隐藏操作禁用，且不遍历歌单判断隐藏状态，取消最后一个勾选仍保持多选。移除顶部收藏/歌单批量删除，单曲菜单保持；从乐库创建或添加到歌单的完成按钮移至浮动按钮，提示同步更新。
- 所选项目含隐藏歌曲时提供取消隐藏：恢复所选隐藏身份及其已知同身份路径副本，其他隐藏记录保持。仅选未隐藏歌曲时沿用隐藏确认。没有删磁盘文件；包含隐藏和普通项目的混选优先恢复隐藏项。

导航栏依据[Flutter contrastEnforced说明](https://api.flutter.dev/flutter/services/SystemUiOverlayStyle/systemNavigationBarContrastEnforced.html)：透明三键导航栏默认可带系统对比度蒙层；false取消该蒙层。实际厂商系统显示仍需设备核验。

## 取色与运动

- 有真实颜料时排除明度>.55的低饱和浅灰，真实白色/黑灰/单色封面保留中性回退。深色不再强制抬到.38，保留<.28的源明度；其余有限压暗，最高明度.58（鲜艳）/.48（柔和）。饱和度只小幅增加并限幅，不凭空添加色相。
- 颜料分组增加明度距离限制，减少同色相浅色吞掉深色。主副色分配改为交换色槽，保留真实粉色等其他颜色；显著金色维持专用槽，不重复占用副色。底色从最暗颜料推导，降低灰白抬底。
- 四场归一化凸混色保持，衰减由平方改立方：减少远处颜色污染深色中心；.44边缘尺度、无加光/Screen/分层包裹保持。增加一项乘法，不新增渲染pass或逐帧取色。
- 轨道角度为低频速度积分：共同慢变速加每团小幅独立差异，角速度理论为基础.15rad/s的.52–1.48倍；速度、加速度、jerk均连续，不逐帧随机跳速。径向游走、漂移中心、真实颜色借色及41.89秒连续周期保持。各团不会用强烈独立相位挤压邻团。
- 保留29-float ABI、复用buffers/缓存/差量uniform、实际VSync调度、退场冻结、歌词引擎与7%上浮、原生高斯、大色差过渡时长。
