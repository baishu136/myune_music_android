# Android 291：参照视频重做逐字上升

日期：2026-09-14

## 视频结论

- 视频 1 为 Myune 旧实现，高亮主要在原基线上平面推进。
- 视频 2 的当前词会在变亮期间持续上升；完成高亮后不会立即回落，而是在当前行播放期间保持抬起。
- 后续词依次从原基线抬升，形成沿播放方向连续推进的逐词波浪。

## 修改

- 将 Android 290 的正弦“上升—回落”改为单调三次缓出曲线。
- 当前词从 0 位移平滑上升到目标高度，越接近完成速度越柔和。
- 已完成词组合层保持最终上浮位置，直到当前行切换，不再在词尾出现下落或抖动。
- 上浮幅度从字形高度的 12% 计算，并限制在 2—9 像素，适配普通和大字体。
- 垂直绘制区域允许进入外层预留空间，水平方向继续严格限制在当前词框内。

## 性能

- 继续复用已完成词的组合文字缓存，只为组合层增加一次固定绘制偏移。
- 当前词仍由已有 `CustomPainter` 更新，不增加 Widget、Ticker 或文字布局次数。
