# Android 355：Dip → Lift → Retain 与四级 Wave Follower

日期：2026-10-04。版本：`1.0.0+355`，Android 显示 `1.0.0-android.355`。

## 范围与实际管线

修改 `karaoke_motion.dart`、`mobile_lyrics_list.dart`，以及实际负责移动端绘制的 `karaoke_paint_cache.dart`（后者是列表的 part 文件）。保留工作区已有 354 桌面歌词兼容修复，不重置其他文件。不修改播放器、高亮真实词元边界、歌词滚动三种模式、公开设置或动态背景。

旧默认位移为约 1.2–4px、760ms 上浮，未唱与已唱的基线模型不符合本轮要求；布局中计算的字素仍由实际绘制缓存消费，不能只修改未被绘制调用的辅助函数。新的自主上浮、跟随、退出包络均接入该绘制路径。退出完成后旧代码还会将时钟重置到行首；本轮保留冻结的媒体时间及退出端点，防止未唱姿态在最后一帧重现。

## 默认参数与时间语义

- 行高比例 0.27，物理最大位移限幅 2–14px。一般大字号约 10–14px，字号/系统文字缩放变化仍有上限。
- 未唱位移为正值；`dy = (1 - lift) * maxLiftPixels`，唱完 `lift=1`，永久停在标准基线 `dy=0`，不弹起后回落。
- 自主上浮在该字扫光 20% 时启动，在 75% 前结束；时长 `min(260ms, 20%→75% 的时间窗口)`。用户已明确选择优先窗口约束，不能同时宣称快字也有 240ms 最小时长。拖音达到上限后保持，不随长尾回落。
- 曲线为既有 smoothTop 五次平滑曲线，端点速度为零。高亮羽化仍独立计算。
- 四级权重 `[0.38, 0.22, 0.12, 0.05]`，每跳媒体时间延迟：拉丁字母 50ms，汉字 140ms。
- 中文估计/真实单字时长 `<180ms` 时位移乘 0.70；静态终点仍为零，不留下高低基线。
- 退出仍采用独立 240ms UI 时间，将尚未完成的下沉位移向上收拢至零；已完成字符不下落。高亮渐入/渐出不再作为自主位移的启动系数。

所有自主/跟随时长使用媒体时间：2 倍播放时 260ms 媒体运动相当于 130ms 实际时间。沿用现有统一播放时钟与倍率锚点。暂停冻结，Seek 直接定位，无逐帧积分或字符启动通知。

## 跟随与缓存

每个拉丁字素有独立运动窗口；同物理行内连续汉字可跨真实词元连接。断开空白/词间、物理折行、实际停顿、方向/文字类别变化和复杂原生字形运行。最多读取四个前驱的 **自主** 位移，不能读取其跟随结果递归扩散。

合并采用有界连续包络：前驱权重形成最多 0.38 的预抬升，再与本字自主进度连续融合；自主进度到 1 即直接保留。相邻高度差随真实语速、字号、扫光位置变化，未强制每帧锁定英文 2.5–4px/中文 4–6px，否则将改变时间语义或产生人为跳变。

提供时间戳的歌词保留真实源边界与既有视觉补偿；词元内部字素时间仍属于估算。普通 LRC 沿用连续 PCHIP 扫光前沿，只在缓存构建时反求每个字的 20%/75% 几何穿越时刻，属于合成估算，不宣称真实逐字时间。

前驱索引、延迟、起始/时长、语速减幅预计算到有界长度的 typed buffers。绘制复用 `Float64List` 位移输出，不新建 Map/List/分组字符串，不做逐帧 `TextPainter.layout` 或字形 Picture 构建。沿用两个有限图集、列表局部一个预热备用缓存、完整下伸字形归属及连字/Emoji/复杂文字原生回退。原生回退在字形运行粒度运动，不强拆连字。

为大位移扩展固定绘制表面，并将翻译绘制位置固定下移一个最大位移。静态/延迟路径使用同样的固定留白，未来原文以整体下沉姿态占位；翻译不参加微浮或高亮。**列表 item 高度、弹簧目标与滚动轨迹保持原样**，不因逐字开关改变布局或换行动画。字体缩小时允许短暂绘制溢出，不裁切或通过强制行高压缩字形。

冷缓存未完成的短暂占位采用整段姿态；混合快速/慢速汉字的精细逐字减幅需等缓存就绪。提前预热保留，但不能保证所有任意远距离 Seek 都已预热；需真机进一步观察冷启动衔接。
