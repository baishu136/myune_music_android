# Android 284：逐字歌词与音乐库载入动画

日期：2026-09-14

## 逐字歌词

- 按参考视频重做为“低亮底字 + 高亮文字连续扫过”的稳定排版效果。
- 带逐字时间戳的 LRC 继续使用原始 token 起止时间；“全部”模式为英文按词、中文按字生成轻量时间轴。
- 播放位置变化直接驱动 `CustomPainter`，只重绘当前歌词的高亮裁剪层，不再在每个播放帧拆分并重建 `TextSpan`。
- 多行与自动换行沿用同一个文本布局，高亮会按实际字形盒顺序推进；从右到左文字按对应方向推进。

## 启动列表动画

- 一次性动画控制器上移到首页生命周期，音乐库完成加载且首批歌曲已进入组件树后才认领并启动。
- 移除容易被页面销毁打断的固定延时；动画从首个稳定绘制帧后的下一次垂直同步开始。
- 默认列表仅让首六项参与 620 ms 错峰淡入上移，减少大列表透明图层和变换层。
- A–Z 查看方式单独重做为首十张可见卡片的浅位移、淡入和轻微缩放波次，不再复用大幅列表位移。

## 性能约束

- 歌曲封面仍按可见区域的原优先级加载，没有为等待动画而延迟组件或封面。
- 动画子项用 `RepaintBoundary` 隔离；超出首屏波次的项目不创建动画层。
- 逐字进度更新不会触发歌词列表重建或文本重新布局。
