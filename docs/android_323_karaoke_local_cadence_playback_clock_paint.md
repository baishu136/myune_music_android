# 323：逐字歌词局部节奏、播放时钟和绘制缓存

## 修改

- 以原歌词词元的起止时间为真实边界。词元内无逐字时间的部分按字素数量估算，并结合前后一个字的节奏平滑、限幅；句尾短词长拖音不反向放慢前一快速字符。此估算不等于真实逐字时间。
- 跟随仍由字符自身上浮发起，最多五级，预上浮上限依次为 20%、15%、10%、5%、2%；跨超过 220 ms 的词元停顿断链。高亮时间轴、约 9% 高度、首字有限预启动、缓慢连续上浮及顶端缓冲不变。
- 歌词视觉时钟读取播放器实际输出状态与实际倍率。倍率变化时从当前视觉位置重新锚定；实际输出停止时停止外推，恢复时读取播放器位置。明确的播放页拖动/歌词跳转在 seek 完成后立即通知歌词时钟；普通位置抖动继续按原有限校正处理。
- 在布局阶段缓存局部节奏、断链、相邻词起点和字素索引；每帧复用进度/上浮/分组缓冲区，用整数分组状态取代字符串键。字素回退、透明度遮罩、文本布局及绘制路径保留原行为，字形缓存仍按当前歌词行与布局失效边界限定。
