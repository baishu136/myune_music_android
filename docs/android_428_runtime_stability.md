## 修复

### 播放及退出

AudioService退出时立即使旧文件加载和下一首预载请求失效；未完成的普通/无缝open返回后不能再请求play。音频参数配置每次await后检查退出状态，关闭后不再继续执行剩余倍速、EQ或open。并发dispose返回同一个释放Future，所有调用者等实际stop/dispose结束，仍保持stop失败时finally释放播放器。

PlaylistContentNotifier统一持有原playing、rate、playWhenReady、completed、playlist、duration、mediaSessionCommands、error订阅，以及非Android旧设备列表/当前设备订阅。原高频position和响度仍由现有字段管理，没有新增轮询、音频时钟或播放器。事件处理先同步执行状态部分，Future失败归入原错误通知/日志；尊重忽略错误提示设置。completed和duration去重，仍允许false→true触发下一次自然结束。

退出/释放立即关闭事件入口并取消旧播放请求；释放时另使睡眠计时世代作废，旧元数据/无缝回调不能提交。启动各阶段、迟到的快捷键初始化及最终响度/无缝恢复在关闭后不再启动后续工作，已释放对象不再发布广域通知。关闭信息/错误流，音频输出释放即使失败仍finally释放AudioService；异步dispose失败记录日志。退出也共享一次完成Future。构造函数增加可选AudioService依赖，正式调用仍默认原真实播放器，用于实际状态对象的生命周期测试，不引入第二套播放状态。

### 控件与动画

收藏/播放模式长按、上一首/下一首连跳及全屏歌词横滑复用PlaybackInteractionGuard。只在当前路由、TickerMode可见且前台时允许动作，指针序列绑定触发世代；失焦、后台、路由覆盖或隐藏会作废旧序列，恢复后可开始新操作。实际触发前还读当前路由状态，避免可见性通知晚于动画tick而在新页面背后切歌。不持续逐帧轮询。

全屏歌词退场被取消时恢复完整可见内容，保留原子元素；过期动画完成不再触发切歌或标题回调。已经开始的媒体Future不能物理撤销，但返回前不接受第二次横滑加载，过期完成不重放入场，完成后新手势可用。正常110ms退场、220ms入场和原曲线保持。

连续切歌保留0.6秒与单次加载互斥。失败时停止重复定时器、释放长按持有并恢复可再次操作；可由调用者接收错误，否则当前页显示短暂失败提示。先安装重复定时器再调用第一次切歌，使同步抛错也能停止它。收藏/模式长按仍满0.5秒，Tooltip、短按与原弹窗风格保持。
