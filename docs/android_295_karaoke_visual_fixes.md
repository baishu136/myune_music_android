# Android 295：逐字歌词视觉修复

日期：2026-09-14

## 视频发现

- 当前词上浮时，已播放部分的灰色基线副本仍在，形成明显的上下双影。
- 灰色副本只在整个词元完成后被缓存层隐藏，导致词尾出现一次突兀跳变。
- 默认滚动使用 620 毫秒过渡，而歌词行位移仍为 520 毫秒，换行前段比缩放和颜色变化更快。
- 高亮羽化宽度最高达到 18 像素，放大了字形内部灰白分层和模糊感。

## 修改

- 在绘制基线文字前，使用 `ClipOp.difference` 按实时逐字进度排除已播放区域。
- 差集裁剪只限制本次文字绘制，不清除已有画面，因此不会重现 292 的整行歌词消失问题。
- 当前词的灰色基线随高亮连续退出，词元完成时不再发生整块切换。
- 高亮羽化由字宽的 22% 调整为 13%，范围从 5—18 像素调整为 4—10 像素。
- 保留 291 的上一行 `-0.16`、下一行 `0.22` 位移幅度，将行位移时长与默认滚动统一为 620 毫秒。

## 性能

- 每帧仅为当前词增加少量矩形裁剪指令，不增加文字布局、Widget、Ticker 或离屏清除层。
- 已完成词、未播放基线、词框和文字布局缓存继续复用。

## 验证

- 覆盖从左到右及从右到左歌词的逐字裁剪边界。
- 执行格式化、静态分析、歌词专项测试、完整测试和 arm64-v8a release 构建。
