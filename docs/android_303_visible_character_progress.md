# Android 303：可见的逐字推进

## 录屏结论

302 实机录屏中的短词通常在约 0.1—0.2 秒内完成颜色变化，只有少量可见帧，因此即使内部已经按字符绘制，肉眼仍接近整词瞬间高亮。参考视频则会在更多连续帧中保留“前字完成、中间字过渡、后字未起”的状态。

## 调整

- 对不足 520 毫秒的词元扩展视觉时间窗，扩展量最多为词首和词尾各 180 毫秒。
- 长词元完全沿用原始时间戳，不改变同步。
- 字符上浮窗口由词元时长的 56% 收窄到 48%，形成更清楚的逐字波峰，同时相邻字符仍有充分重叠。
- 继续使用 302 的跨字符宽渐变，渐变从词外进入并从词外结束。

## 性能与同步边界

改动只调整已有视觉进度，不增加计时器、布局或绘制层。短词最多提前和延后 180 毫秒，避免为了动画可见度产生明显的歌词同步偏移。
