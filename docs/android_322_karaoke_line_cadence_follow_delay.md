# 322：逐字歌词跟随延时随歌词行推进速度变化

## 修改

- 按当前歌词行所有可绘制词元的有效演唱时长与字素数量，计算该行的平均单字推进时间。
- 后续字符的连续跟随延时改为该推进时间的比例：快行延时短，慢行延时长；跟随启动和上升时长都随行速变化，不再使用固定的位移阈值。
- 继续只由字符自身的上浮发起最多五级跟随，保留 20%、15%、10%、5%、2% 预上浮上限，避免接力再次传播至整行。
- 321 的缓慢上浮窗口、下一字符起亮时前一字符到顶、词尾按自身速度完成、9% 高度及顶端缓冲保持不变。
- 将行速、字符上浮起点与首字符预启动信息在字形布局阶段缓存，避免每帧重复计算时间轴。
