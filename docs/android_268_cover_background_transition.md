# Android 268：封面背景切换稳定性

## 问题原因

播放页在“流体色彩”和“模糊封面”之间切换时会直接替换整个背景组件。流体 Shader 已被移除后，模糊封面的首帧仍可能处于图片解码阶段，于是底层背景会短暂露出，视觉上表现为闪烁。

## 改动

- 切换到模糊封面前预解码与实际背景相同规格的封面图片。
- 图片可绘制后再替换背景，并使用 280 毫秒的纯透明度交叉过渡。
- 背景切换期间保留旧背景，避免透明帧。
- 前景页面独立于背景过渡，只保留一份，不重复构建播放控制、封面或歌词组件。
- 增加固定底色兜底，异常图片也不会露出透明窗口。

## 当前通知栏播放器可见内容

应用当前向 Android Media3 发布：

- 应用媒体卡片及歌曲封面。
- 歌曲名、歌手名，并提供专辑元数据；具体文本组合由系统界面决定。
- 上一首、播放/暂停、下一首。
- 桌面歌词状态按钮；受系统媒体卡片槽位限制，部分 Android 版本会将其放入展开区或溢出区。

应用未发布 `seek` 能力，因此通知栏进度条不会主动显示。Android 系统可能调整按钮顺序、隐藏没有可用目标的上一首/下一首，或显示系统自己的输出设备入口，这些不属于应用自定义组件。
