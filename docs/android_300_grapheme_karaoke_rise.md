# Android 300：逐字跃起与柔和过渡

## 问题

此前上浮进度直接绑定歌词时间轴中的词元。带逐词时间戳的英文歌词会将一个完整单词作为一个词元，因此视觉上只能逐词上浮，无法形成参考视频中的逐字波浪。

## 实现

- 保留原有词元时间轴，不改变歌词同步与跳转逻辑。
- 仅在当前播放词内部按 Unicode 字素簇拆分绘制范围，组合音标、连接 emoji、阿拉伯文等不会按 UTF-16 代码单元错误拆开。
- 在一个词元的时长内为各字符分配相互重叠的局部进度，使前一个字符尚未完成时下一个字符已经柔和起跳。
- 每个字符沿两端零速度的 S 型曲线独立完成上浮与渐亮；所有字符仍使用统一排版行高确定最终位置。
- 继续使用单份字形渲染。平台无法可靠映射的复杂字形会整词回退为静态绘制，避免半个连字消失、重影或截断。

## 性能边界

完整词与未播放词仍合并缓存绘制，只有当前播放词按字符绘制；排版结果和字符画笔在布局宽度不变时复用，不会在每一帧重新拆词或重新测量整行。
