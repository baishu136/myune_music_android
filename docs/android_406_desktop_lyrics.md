# Android 406：桌面歌词逐行缩放、逐字颜色及对齐

日期：2026-10-17。版本 `1.0.0+406`，正式 ARM64 versionCode `2406`。

## 行为

- 桌面歌词设置新增“动态调整桌面歌词字体大小”，默认关闭。开启后，按每个原始歌词行的实际可用宽度单独缩小，预留描边与字缘空间；短行仍采用设定字号，下一句重新计算，不写回字体设置。关闭后保留原来的最多三行折行显示。设置预览同步变化。
- 新增独立“桌面逐字歌词”，默认关闭，不改变播放页的逐字开关或范围。优先使用原文/翻译各自有效且文本完全匹配的时间信息；普通 LRC 仅能按现有规则估算原文的推进，不能推断真实演唱时间。无时间的翻译、间奏与暂无歌词保持原色。
- “已播放部分颜色”可自定义并持久保存。尚无自定义时，从原歌词色与描边色计算兼顾两者的最大最小亮度对比颜色；手选颜色不会因修改正文/描边或重启而被覆盖。“恢复默认”清除高亮色覆盖，并恢复新增开关关闭、居中。
- 新增左对齐、居中、右对齐，默认居中，桌面悬浮窗与预览一致。没有添加新设置说明、底部注释或 InfoIcon。
- 保留原描边颜色、粗细和透明度，仅改变已播放文字的填充颜色。原生字号上限由旧的 36 修正为与设置一致的 40。

## 绘制与数据链路

`DesktopLyricPresentation` 生成显示文本与 UTF-16 时间范围，保留复杂字素和翻译偏移。原生按字素缓存显示位置，在已有文字布局上裁切高亮；连续帧不重新布局、计算字号或传整行跨端数据。播放时约每 800ms校时，换行/暂停/倍率/显式 seek 及时同步；小范围上报抖动不使连续高亮回退，seek 标识改变则直接定位。暂停、完成和窗口脱离后不继续申请连续重绘。

每行字体采用原生测量后独立字号 span；宽度/内容/字体/字号/描边改变时重新计算。保留文字语义、锁定穿透、拖动、控制按钮、服务前后台抑制和原淡出行为。首次启动服务使用标准消息编码保存完整 payload，补齐旧 Intent 路径遗漏的字体、描边及新增字段。

实际播放页歌词、405共享滚动/正文缓存、394背景混色和音频 DSP 没有修改。以405不可变源码 ZIP 逐文件对照检查范围，保留402～405未提交工作；未提交、推送、创建 tag 或 Release。
