# Android 260：恢复播放页功能区毛玻璃

日期：2026-09-11

## 改动

- 恢复播放页统一功能弹层的真实背景模糊，覆盖歌曲详细信息、均衡器预设、自定义均衡器与音频效果、歌词字体大小、复制歌词菜单、歌词设置及播放队列等区域。
- 流体背景下使用 `sigma=5`，普通封面背景使用 `sigma=7`，保留半透明填充与边框以维持文字可读性。
- 两种模糊滤镜在播放页状态类中预创建并复用，避免歌词字号滑动或均衡器交互时重复分配滤镜对象。
- 功能弹层打开后，底层播放路由不再是当前路由，流体控制器会保留静态画面并停止调度；模糊采样的是稳定背景，不与流体动画持续并行。
- 主播放控制区和底部工具栏仍保持 254 版无模糊设计，避免常驻区域增加持续合成成本。
