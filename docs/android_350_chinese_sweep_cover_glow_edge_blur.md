# Android 350：中文连续扫光、动态封面边缘光与视口景深

日期：2026-10-03。以实际 349 工作区继续修改；保留原有未提交成果，无 Git 重置、提交或推送。版本 `0.9.9+350`，仅构建 ARM64。

## 查明的问题与修改

1. 普通 LRC 的合成中文时间轴原先给纯空白分配 `.25` 权重，并按字符位置使用 `.72/1/1.3/1.8` 的权重阶梯，凭行时间戳人为生成速度变化。修复前的复现测试测得示例中的空白占用约 281588 微秒；现在保留空白文本/布局，但分配零时间，中文字符采用等权估算。保留既有语言占比决定的有效演唱窗口、有限提前量和上下限，不宣称估算是真实演唱时间。
2. 虽然 349 已跳过字形几何间隙，相邻合成 Token 的羽化前沿仍分别重新开始；修复前真实排版复现中，前一字末尾前沿约 30.5，后一字起步回到约 21.5。新增 `KaraokeSweepTimeline`：在布局阶段把同一物理折行、同方向、时间连续的合成片段连接为一条可见推进路径，用单调 PCHIP 连接累计距离，速度在估算边界连续，不超调。绘制只查询缓存时间轴与路径。折行、方向改变或不连续时间断开连接。
3. 连续扫光只用于合成歌词。真实逐字歌词仍使用原始时间、现有视觉补偿与停顿；真实时间之间的空隙不被抹除。已有微上浮、行滚动三模式、翻译弱化、透明度合成、完整墨迹/复杂文字回退保持不变。
4. 封面页新增固定两层边缘光：主题色透明度 `.34`、模糊半径 18、扩展 1.2；白色透明度 `.18`、模糊半径 3、扩展 `.6`。使用实际解析出的流体动态背景开关，不是仅判断设置中选了流体；关闭播放页封面背景或改用其他背景时无光圈。保留 Hero、封面更换动画和尺寸，没有额外 ticker、封面解码或背景滤镜。
5. 歌词模糊开启时，在现有基础景深上按距视口上下边缘的距离增加最多 `2.4 sigma`，上下对称，过渡带为视口高度的 24%（限幅 80–180px），SmoothStep 加 `.2 sigma` 量化。当前正播行、浏览选中行和间奏退出保持清晰；模糊关闭时不生效。
6. 景深使用一个 `ImageFilterLayer`，不叠加第二层模糊。渲染对象监听既有滚动控制器，只更新滤镜合成层，不逐帧重建 Widget 或排版。滤镜银行固定 121 项（0–6，步长 .05）；滚动边缘采用更粗的 .2 步长。保留原焦点景深变化与滚动期间静态基础模糊策略。

## 职责与文件

- `lib/widgets/synthetic_karaoke_timing.dart`：只估算缺少逐字时间的歌词，空白零权重、中文等权。
- 新增 `lib/widgets/karaoke_sweep_timeline.dart`：确定性的合成推进时间映射。
- `lib/widgets/karaoke_sweep_path.dart`、`karaoke_paint_cache.dart`：布局阶段组装物理折行路径，绘制消费缓存；不增加逐帧 layout。
- 新增 `lib/widgets/lyric_viewport_blur.dart`、修改 `mobile_lyrics_list.dart`：视口景深与缓存合成层。
- 新增 `lib/widgets/now_playing_cover_glow.dart`、修改 `lib/mobile/mobile_shell.dart`：封面边缘光及实际流体背景条件。
- 新增时间轴、边缘模糊和封面光圈测试，扩充合成与墨迹回归测试；原模糊测试改为识别 `ImageFiltered` 子类，不修改原断言语义。
- 新增 `integration_test/chinese_sweep_depth_performance_test.dart`；版本、项目变更记录与版本测试更新。

## 已知限制

边缘景深按测量的行中心计算，一整行使用同一 sigma；不是长折行内部的逐像素渐变。中心计算不含动感/弹性模式额外的局部行位移，边缘景深位置是近似值，不为此改动原滚动模式。模糊本身仍有 GPU 成本；静态滤镜缓存和合成层更新不代表渲染成本为零。未提供独立 GPU 内存、功耗或不同机型的稳定性结论。
