# Android 380：全屏歌词滑动切歌提示

日期：2026-10-11（Asia/Shanghai）。用户要求按示意图，在全屏歌词滑动切歌成功后于顶部短暂显示小封面、歌曲名和歌手。

## 行为与实现

- 沿用全屏歌词横向滑动手势。旧歌词退出、播放器切换完成后，回调携带切换前歌曲身份；播放页读取播放器已提交的当前歌曲，身份实际变化才发布提示事件。`_startPlaybackNow` 在新文件成功加载后才提交 `currentSong`；解码失败会保留旧身份，因此不会把失败或单曲队列重播当作成功换曲。
- 顶部安全区内左侧显示44dp圆角封面，右侧上方歌名、下方歌手；左右留16dp，平板28dp，最大宽420dp。两行文本分别单行省略，随系统字号变化。
- 首次160ms淡入，事件发生后2200ms开始240ms淡出。快速切歌更新为最新元数据并重新计时，正在淡出时从当前透明度恢复，不从零闪入；系统减少动画时直接显示/隐藏。
- 退出全屏、切回封面、路由退出、进入后台或外部换到另一首时清除；恢复和重新挂载不重放旧事件。未成功完成的加载、取消/短滑/纵向/双指手势以及自动/其他入口切歌均不主动触发提示。
- `FullscreenSwipeSongHintController` 是事件通知器，相同缓存Song对象也可重复通知。浮层有独立State、计时器与淡入淡出控制器，单个RepaintBoundary及IgnorePointer，不占歌词布局空间，不拦截歌词触摸；没有第二套歌词、Hero或背景模糊。
- 封面复用已有 `_Cover` 的缩略图请求、按歌曲订阅与192px解码缓存；没有封面或解码失败显示现有音乐图标。新歌曲使用独立key，避免复用上一首图片。只请求小封面，完整播放封面和背景仍按原流程准备。

主要文件：`lib/widgets/fullscreen_swipe_song_hint.dart`、`lib/widgets/lyrics_song_swipe_transition.dart`、`lib/mobile/mobile_shell.dart`。
