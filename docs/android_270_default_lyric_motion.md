# 0.9.9-android.270

## 视频对比

- 参考视频 1 的歌词换行从起动到视觉稳定约为 600–620 ms。
- 当前视频 2 的主要位移约在 250–350 ms 内完成，文字强调仅持续 210–280 ms，造成明显的快速跳转感。

## 调整

- 默认歌词滚动的临界阻尼频率由 `12.5` 降至 `8.8`，保留连续速度与解析解，延长位移的柔和收束过程。
- 默认模式的位移、文字颜色、透明度、缩放及歌词行模糊统一按 620 ms 节奏变化，使用同一柔和曲线，避免不同视觉属性先后突然结束。
- 开启“歌词弹性滚动”时仍使用原有弹性脉冲、延迟和聚焦时长，不受本次调整影响。

## 性能

- 不增加动画控制器、列表重建范围或离屏缓存范围。
- 滚动仍使用每帧一次的临界阻尼解析计算，延长的是视觉时间，不增加单帧计算复杂度。
