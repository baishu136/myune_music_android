# Android 294：默认歌词行位移

日期：2026-09-14

## 视频对比

- Android 293 的逐字模式已经保留 291 的行切换方向：上一行继续上抬，下一行从下方归位。
- 关闭逐字歌词后，该位移因开关条件被禁用，默认滚动只剩列表移动、缩放和明暗变化，与参考视频的切换层次不同。
- 逐字上浮、高亮推进和已完成词保留在最新视频中工作正常，本次不修改其绘制参数。

## 修改

- 解除歌词行位移对逐字歌词开关的依赖，使默认歌词滚动同样应用该动画。
- 保留 291 的位移参数：上一行 `-0.16`、下一行 `0.22`。
- 保留 291 的 520 毫秒持续时间和现有缓动曲线。
- 手动浏览歌词时仍停用自动行位移，避免跳转框位置与触控目标发生偏移。

## 性能

- 继续使用 `AnimatedSlide` 的合成层位移，不触发布局重算或文字重绘。
- 不增加 Ticker、监听器、模糊层和逐帧文本测量。
