# Android 403：播放弹层、选歌记忆与连续切歌

日期：2026-10-17。版本 `1.0.0+403`，正式 ARM64 versionCode `2403`。

本轮基于已完成但未提交的402；Git main基线仍为 `08437fb5ad95dc433dce2fc28ef31edad5fd5073`。402完整源码ZIP取自不可变备份，SHA256为 `F60A78C6323070F96B6A0012145B0C868558E5E199D1BA0C892C6AC2F60B9346`。保留所有既有修改、应用数据、历史APK与源码，不提交/推送/tag/Release。

## 实际改动

- 循环随机模式采用外圈循环箭头与内部随机交叉箭头的组合矢量图标，播放页、模式列表、通用模式按钮一致。24/28/36逻辑像素沿用前景色，不引入新图片或字体。
- 播放模式长按改为从底部进入，高度82%；取消内层不透明Scaffold/AppBar，保留模式、次数、语言过滤操作及关闭按钮。模式、收藏长按、封面长按共用同一弹出方法：进入260ms、退出220ms，键盘底部避让、安全区及圆角相同。
- 三个面板复用既有播放控件表面：顶部圆角28，动态背景底色28%/模糊5，其他播放主题底色10%/模糊7，描边72%；浅色主题仍使用原白色前景处理，未启用播放主题时统一使用Material主题回退。其他使用原共享表面的播放面板参数保持。
- 选歌控件记住音乐库/歌手/专辑/搜索/歌单分栏，及打开的歌单ID、搜索词和列表位置；写入本地设置，关闭再开及重启可恢复。记忆不改变实际播放来源。按当前歌单ID重新解析对象，歌单删除后留在歌单列表，列表缩短时限位，不保留过期歌单对象。
- 连续切歌仍长按识别后立即切一次，周期由2秒改为1.2秒；原短按不变。同键慢加载不重叠，松手/取消/销毁/退出前台停止重复。维护手势与所有在途加载的独立所有权，松手后若最后一次仍加载，轻量状态保持到加载完成；重复释放、多个持有者及迟到完成不会提前恢复。
- 轻量状态下保留音频及所选曲目的封面/标题更新，歌词保持旧身份和显示进度、断开实时进度/播放/变速/seek监听并停Ticker；背景保留同一Widget并停Ticker，不为每首中间歌曲重新取色/加载歌词/预热/校验元数据/更新通知与保存进度。原已排队的自动排序等待空闲保护结束，避免丢弃必要排序。
- 最后一次加载结束后，用播放器实际位置恢复最终歌曲的歌词、背景、预热和状态保存。原空闲调度按租约分批处理重任务；中间曲目不被补做。没有实际成功换曲时继续原收听累计时间，成功换曲才开启新的累计；外部播放控制也不在连续切歌时重启统计计时器。
- 歌单首页底部导入按钮仅在选中“总歌曲”的卡片视图出现；未选歌单及其他歌单不显示。分栏视图沿用原页内入口，普通歌单仍可从库添加。
- 主页顶部标题和操作按钮沿用300ms横移动画，进入/退出叠加分段透明变化，分别从12%/35%动画进度开始显现（退出时反向），不添加时钟或布局动画。
