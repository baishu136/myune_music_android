# 0.9.9-android.246 后台返回优化

## 优化

- Android UI_HIDDEN（20）是可见性通知；当前 Flutter embedding 对 >= RUNNING_LOW 的等级发送内存压力消息，造成 Dart 图片缓存释放及再次解码。仅将 UI_HIDDEN 传给父类时映射为 RUNNING_MODERATE，真实内存压力等级原样转发，onLowMemory 不变。
- 图片缓存容量仍为原有 320 项 / 48 MiB，不扩大容量，不禁用系统真实内存压力处理。普通后台切换期间缓存可能保留更久。
- inactive 保持之前的前后台状态，避免通知栏、权限界面等短暂失焦重复取消位置订阅、重启封面恢复；hidden/paused/detached 仍停止 UI 位置订阅，resumed 即时恢复。
- 恢复时仅在图片缓存代次变化后失效封面预热记录，避免取消仍有效的异步解码；准备记录还会核对 Flutter 图片缓存是否实际存在，已回收资源仍能恢复。
- 不修改播放、歌词动画、组件加载时机、缓存大小及后台音频服务。

## 验证

- Flutter 测试 179 项通过，包括新增的失焦/后台生命周期状态测试。
- 真机尚未连接，未取得帧耗时对比；不能保证所有机型无卡顿。
- 建议真机验证：播放中 Home 返回、通知栏展开收起、后台切歌后返回、权限界面返回、低内存回收后返回。检查封面、歌词时间、桌面歌词及播放控制，并比较 FrameTiming/Perfetto 的慢帧数据。
