# 0.9.9-android.248 播放页与歌词优化

## 修复与优化

- 播放页大封面尚未预解码时，直接使用当前已有封面做渐进加载，不再先显示音符占位。
- 播放页路由转场改为 520 ms，返回为 460 ms，并允许 Flutter 在转场期间使用页面快照，减少两个页面同时重绘。
- 默认歌词滚动由 520 ms 放缓到 680 ms，改用 easeInOutCubic，多行歌词位移更缓和。
- 参考 ZeroBit-Player 1.6.0 将歌词渲染区向上下各延伸 180 dp，屏幕仍按原范围裁剪，避免高歌词行、翻译和弹性变换在完全离开屏幕前被 sliver 剔除。
- 弹性滚动降低刚度、提高阻尼，并将同时运行的分行弹簧从最多 13 行收紧为 9 行，降低多行歌词切换时的调度和绘制压力。
- 顶部渐隐边缘保留轻微不透明度，剩余文字在越过屏幕边缘前仍可见。
- 移除“进入播放页时展示”界面与持久化值，新旧安装均从封面页进入。

## 性能边界

- 屏外渲染会额外保留少量歌词行，因此内存和布局工作会有小幅增加；同时将缓存区固定为 240 dp，且减少弹簧行数，避免随歌词数量增长。
- 不改变歌词获取、翻译、跳转、封面解码清晰度和播放控制。
- 181 项 Flutter 测试和静态检查通过；当前无连接真机，尚无真机帧耗时与内存峰值对比。
