# Android 359：中文、日文短间隔柔和连续上浮

日期：2026-10-04。源码版本 `1.0.0+359`，显示版本 `1.0.0-android.359`。

## 实际问题与修改范围

以实际 358 工作区和源码留档为基线。357 的三阶轻牵引本来已接入英文、汉字、假名和混排，并非中文完全没有位移；但生产绘制缓存只允许跨词元约 2ms 的时间戳间隙，中文、日文单字词元存在短间隙时会频繁断开跟随。

只修改逐字运动的缓存连通规则，不修改播放器、行级滚动、高亮时间轴或动态背景。在 `karaoke_motion.dart` 集中定义紧凑字素识别与运动连通规则；实际移动端调用路径是 `mobile_lyrics_list.dart` 的 part 文件 `karaoke_paint_cache.dart`，因此修改该缓存，而不改未被生产绘制调用的旧辅助算法。

相邻完整 Han/kana 字素（含组合浊音、异体选择符及安全塑形片段）的跟随允许短时间戳间隙：容差为相邻两个原始词元较短时长的 35%，默认最大 80ms，且保留原 2ms 量化容差。英文和其他脚本保持旧连通条件。长拖音不能抬高短邻字的容差；长停顿、空白、物理折行、文字方向变化和倒序时间仍断链。

该容差仅影响预牵引，不填补真实演唱停顿，不移动真实词元起止或现有视觉补偿，也不宣称词元内部字素估算是真实逐字时间。真实高亮的短间隙仍存在；本轮目标是运动连贯，不是修改唱词时间。

## 保留的柔和参数与性能路径

- 354/357 基线不变：高度 `.055 × 排版行高`，限幅 1.2–4px；自主运动 760ms **媒体时间**、smoothTop 曲线，最多 35ms 自主预启动。
- 三阶轻牵引 `[.24, .12, .05]`，沿用剩余行程融合；每个字符最多读取三个前驱的自主运动，不递归传播跟随结果，不增加上浮总高度。
- 唱完保持原高位，退出仍采用原 240ms 包络；暂停、倍率及 Seek 继续由既有统一媒体时钟决定。未恢复 355/356 的大幅下沉归位方案。
- 脚本正则、局部时长与连通判断仅在布局缓存创建时运行，前驱索引存入有界 typed buffers。逐帧运动、绘制循环、图集、塑形回退、透明度合成和翻译静态显示不变；没有新增逐帧排版或字符串判断。
- `maxCompactFollowerGap` 内部参数默认 80ms，校验范围 0–120ms；设为零可恢复 358 的 2ms 连通条件，不新增用户设置。`followerWeights=[0,0,0]` 仍可回到 354 自主运动作对照。
