# 0.9.9-android.269

## 动态背景

- 保留 `colorgram` 的封面颜色占比，将主色占比一路传递到片元着色器；主色拥有更宽的连续色域，小面积点缀色不再与主色等面积显示。
- 继续只绘制四个低频色彩场；第 5、6 个候选色按色彩距离合并到最近主色，避免增加全屏逐像素计算量。
- 播放页可见且路由动画结束后，惰性监听播放器已有的 FFT 数据，以低频 RMS、全频 RMS 和低频瞬态估算节奏强度。
- 速度采用快速响应、缓慢回落的包络；暂停或 FFT 中断后自动回到基础速度，背景不会停止。
- 路由切换、进入后台及减少动态效果时释放 FFT 监听，避免不可见页面继续进行音频分析。

## 歌词滚动

- 默认歌词滚动的临界阻尼运动改为解析解，每帧只计算一次；长帧后的位置与速度仍连续，不再依赖多个欧拉积分子步。
- 歌词底部淡出增加完全透明缓冲区，清除短单语歌词行在歌词区底边残留一行的现象。

## 性能边界

- 不新增封面解码流程，不逐帧重新取色，也不重建歌词列表。
- FFT 管线由播放器按监听者数量自动启停；背景侧每帧仅遍历现有频段并更新一个标量速度包络。
