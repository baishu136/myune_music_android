# 425 分散柔和的氛围色场

2026-10-25；1.0.0+425，ARM64 versionCode 2425。在完整424工作区上增量修改，保留此前未提交成果；HEAD仍为419～423源码提交`b6e5604`（尚未推送）。本轮不提交、推送或发布Release，应用内更新日志仍为412。

## 根因与修改

- 424虽然用低频扰动弯曲了坐标，最终颜色仍由两条贯穿屏幕的曲面划为四角区域；权重响应继续强化了大片内部，因此仍会出现半屏色板、斜向切面及楔形轮廓。只减小位移或放宽混色范围无法去掉这个基础结构。
- 425移除两条分区曲面，改为覆盖整个显示区域、方向和尺度不同的两组连续梯度浓度场。每种颜色在多处交叠分布，不再占据一个固定角落或完整大面。后一个场受前一个场轻微带动，形成局部渗透和形变。
- 采用三角采样的平滑梯度场，避免方格值插值留下的平顶方块；只有两组固定场、不叠加多层噪声，不把场值作为颗粒或灰色纹理绘制。最终空间频率控制在短边1.30/1.55尺度，避免早期候选过碎；按屏幕短边计算，横屏、竖屏和平板的局部尺度一致。
- 浓度保留正的交叠支持，并用平滑凹响应压低近纯色内部。去除原有强化大分区的权重响应，颜色交界保持宽而连续，没有硬阈值切割、扇形或直线推进。主色可分散占优，但不再通过一整片近纯色表达。
- 在不改变封面取色、原始饱和度与明暗风格的前提下，混合后的色度损失恢复上限由1.16调整至1.40，并继续限制在原输入加权色度及有效色域内，避免分散混合后发灰；单色/中性色不会统一加饱和度。没有额外提亮、光斑、粒子或发光层。
- 动画控制器、35项参数布局、切歌及快速重定向、背景快照、歌词/封面切页状态、质量档位、减少动画、生命周期和手势调度不变；统一参数文件只修正文档注释。保持单pass、一次矩形绘制，无新增纹理、离屏层、Ticker或后台轮询。新的梯度核有固定额外算术，不将角点采样数减少直接等同于GPU提速。

## 验证方式与范围

- 新增真实生产着色程序的逐色“红色染料”测试：一次只让一个色槽贡献红色，其余为黑色，观测该色场的实际覆盖、相邻像素变化及局部浓淡差异。这样不能靠选择相近封面颜色掩盖巨大色场。
- 取整个原动画周期内25个等距时刻，加18/61/123/187秒；3种长宽比、4个色槽，共348组。固定门槛：染料值≥90/255的最大连通强色域≤30%，峰值≤165/255，短边96/128采样图的相邻红色差≤12/255，画内变化范围≥12/255。该定义测量颜色场集中程度，不等同于用户看到的某一色相面积；它也不是对任意封面、任意连续时间的数学证明。
- 外部独立Flutter宿主从不可变424源码ZIP提取原着色文件，使用同一参数布局和完全相同的测试；424复现失败，425通过。348组中旧版240组触发门槛，旧最大连通强色域60.52%、染料峰值220、最大相邻差14；新版0组触发，最大连通强色域29.02%、峰值147、最大相邻差9，最小画内变化范围53。未为当前实现放宽断言；早期候选边界过急时的失败记录保留。
