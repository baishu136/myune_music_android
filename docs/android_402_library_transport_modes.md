# Android 402：总歌曲歌单、长按操作与播放规则

日期：2026-10-17。版本 `1.0.0+402`，正式ARM64 versionCode `2402`。基于401完成源码，Git基线 `08437fb5ad95dc433dce2fc28ef31edad5fd5073`。本轮不提交、推送、tag或Release，不清空应用数据，原歌词、394背景及音效参数保持。

## 播放页操作

- 上一曲/下一曲短按保持单次切歌；长按确认后立即切一首，保持按住期间每2秒再切一首，松手、手势取消、退出页面、隐藏或应用非前台时停止。等待一次加载结束后才允许同一按键发起下一次，慢加载不会叠加请求。没有常驻定时器。
- 长按收藏键打开底部歌单选择面板，顶部“新建歌单”，下方已有歌单及复选框。可以连续加入多个歌单，已加入项保持勾选且不重复添加；新建并命名后直接包含打开面板时的歌曲。底部“完成”关闭。总歌曲不作为重复添加目标；短按收藏仍只切换收藏。
- 长按播放模式键进入独立页面，可选择列表循环、随机播放、单曲循环、新增的“循环播放后随机播放”。新模式自动播完时仍循环当前曲，手动上一曲/下一曲按随机顺序切换；原三个模式的持久化编号不变，新模式追加在末尾。
- 原按钮Tooltip会优先消费长按，初版回归实际复现入口未触发；新长按按钮保留提示语义/悬浮能力，并关闭Tooltip的长按触发，手势由功能本身处理。长按不再同时触发短按。

## 总歌曲与旧数据

新增固定ID `library-root-402` 的“总歌曲”，带音乐库图标，始终位于歌单最前；不能重命名、删除或挪到其他歌单后。它单独拥有曲库原始路径，包括已隐藏项和不同来源；显示、计数、排序、置顶、隐藏/恢复、多选与播放使用音乐库的同一份可见歌曲、排序范围和播放上下文。隐藏不删除文件或清除原始归属。

初次恢复时将已有各歌单来源合并进总歌曲，保留旧歌单ID、收藏内容、文件夹关联及原文件。新安装的收藏为空；已有收藏无法可靠区分历史自动加入和主动收藏，因此完整保留，不擅自清空。此后单曲/文件夹导入只进入总歌曲，不再自动收藏。取消收藏或删除普通歌单，不再让歌曲从曲库消失。

歌单页卡片与分栏两种布局均提供总歌曲入口。普通歌单的“添加歌曲”改为从音乐库选择；仅总歌曲可打开文件/文件夹导入。原文件夹歌单继续保留，可通过既有高级页管理刷新/移除关联；不再从新建普通歌单入口直接导入新文件夹。导入选择器打开前固定目标，避免期间改变选中歌单导致导入到错误歌单。异步旧歌单加载完成后也核对当前选择，不覆盖总歌曲视图。

旧元数据读取失败仍只在内存降级，不立即写回或清理旧歌曲文件；从旧顺序恢复的路径先放入内存的总歌曲归属，避免启动恢复时破坏旧文件。

## 切歌过滤与预加载

播放模式页面提供四个独立开关，默认关闭：收听次数低于最低值、英文标题、日文标题、中文标题。最低收听次数默认10，可输入非负整数；恰好达到阈值可播放。沿用现有超过30秒才计次的统计规则，不按短暂切歌次数新增收听。

标题只按文字识别：含假名判日文，含汉字且无假名判中文，其余含拉丁字母判英文；纯数字/符号保留。这不是语言识别服务，纯汉字日文名会按中文处理，其他拉丁文字语言也可能归入英文；混合标题按上述优先级，不按歌手或歌曲实际演唱语言推断。

手动前后切歌、自动播完和无缝预加载共用一次最多遍历当前来源长度的选择函数，过滤条件组合生效。直接点选歌曲不受过滤限制；单曲自动循环不是换歌，不应用过滤。全部不符合时，手动不改变当前曲并提示，自动结束停止，不无限重试。队列结束后停止设置仍优先于自动循环和自动越界。

快速调整规则的专项红测确认原 `AudioService.replaceNext` 并发移除/追加会留下旧预加载：期望latest或空，实际仍outdated。最终将预加载替换串行执行，按最新请求、歌曲加载代次和销毁状态丢弃过期工作；最新清空也能生效，清理多余待播项但保留当前项。失败的可选预加载不打断当前播放。无逐帧或定时轮询，音量/DSP图不变。
