# Android 285：逐字歌词动画重做

日期：2026-09-14

## 目标

参照 `Screenrecording_20260912_173810.mp4`，将逐字歌词从单纯的硬边横向裁切升级为完整、连续的歌词动画，同时维持稳定排版和低额外开销。

## 实现

- 当前词使用带羽化宽度的方向渐变遮罩，形成柔和的逐字高亮前沿。
- 高亮前沿增加低透明度、有限模糊半径的轻量光晕，避免硬切但不过度发亮。
- 使用独立视觉播放时钟在播放器进度回调之间连续推进，并用 45 ms 指数纠偏吸收回调抖动。
- 大幅跳转、应用恢复及较长掉帧直接同步真实位置，避免视觉进度追赶或漂移。
- 暂停立即停止视觉时钟；静态预览不启动逐帧刷新。
- 保留并同步现有行级上移、缩放聚焦、旧行降亮及距离模糊动画。

## 性能约束

- 歌词文本布局和逐词字形范围按行缓存，播放进度只触发 `CustomPainter` 重绘，不重建歌词列表。
- 每帧只处理当前部分词的柔边图层，已经播放完成的词合并为单一路径绘制。
- 柔边宽度限制在 5–18 像素，光晕半径固定，避免大字体下图层范围无界增长。

- 运行歌词列表专项测试、全量测试、静态分析和 arm64 release 构建。
