# 423 网格柔和传递渐变背景

2026-10-24；1.0.0+423，ARM64 versionCode 2423。保留419～422全部未提交成果，本轮不提交、推送或发布GitHub Release。应用内更新日志仍为最后实际发布的412，后续获授权发布时再合并。

## 实现

- 当前动态背景替换为固定规则网格：屏幕短边分为10个间隔，四个相邻节点之间柔和混色。区块的位置固定，以颜色变化表现运动，不移动旧色团，也不叠加第二层动态背景。
- 使用原取色及持续变色链路的三组主色，从屏幕中心沿不规则圆环向外传递；圆环轮廓由区域变化轻微打散。饱和度相对提高10%（乘1.10，最大为100%），保持色相、明度，中性色不额外染色。
- 随机局部变化只调整所在区域已有颜色的明暗。三个错峰、缓入缓出的区域在完全不可见时才更换位置，采用可重复的散列分散位置。包括网格插值的可见范围在内，直径不超过旧色团尺度的70%；以四个旧形状参数中较小的轴向尺度作保守上限，避免插值使实际范围超限。
- 深色从原色组平滑提取，分散在互相隔开的不规则网格位置，以错开的阶段传播、淡入淡出；有深色时不让它作为整圈暗带扩散，亮色封面不人为加入黑色。纯黑、纯色封面仍依原取色保持相应特性。
- 原有切歌中间色与跨度时长、预热/调度、低运动模式、暂停/后台/遮挡处理、恢复与快照缓存、暗度/边缘暗角/微量抖色保持。歌词、音频、其他页面和设置没有本轮功能改动。

## 性能与兼容

- 单次背景绘制、单个着色程序，不增加常驻Ticker、离屏混合层、纹理或后台轮询。34项浮点参数复用缓冲，仅上传变化项；每帧不创建颜色/区域对象。局部明暗范围使用平方距离，省去每像素12次开方；仍需实机验证实际GPU耗时，不将算术减少换算为帧率提升。
- 保留原49参数计算接口与旧着色文件供历史回归，实际播放页明确加载新的网格着色文件。画笔按使用分支延迟创建参数对象，生产路径不会同时运行两套着色。旧色团形状测试只代表历史接口回归，不冒充当前网格视觉验收。
