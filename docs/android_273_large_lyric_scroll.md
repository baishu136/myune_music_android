# 0.9.9-android.273

## 大字体歌词滚动

- 20px 及以下继续使用 8.8 的默认滚动频率和现有动画距离。
- 20–36px 之间根据字号连续插值，滚动频率逐步降低至 7.2，避免行高增加后像素速度同步放大。
- 大跨度自动滚动的可见行程由视口高度 42% 平滑降低至 32%，减少一帧内进入布局和绘制区域的歌词内容。
- 大字体弹性位移的视口占比由 36% 平滑降低至 31%，最大值由 156 调整至 140 像素；大字本身更高，因此仍保留明显回弹视觉。

## 连续性与性能

- 动态参数更新不会清零当前偏移、目标或速度，避免切换字号时产生新的方向抖动。
- 歌词行高仍提前测量并通过 `itemExtentBuilder` 提供，不增加滚动期间的文本测量。
- 未新增逐行 Ticker、离屏缓存或动画控制器。
