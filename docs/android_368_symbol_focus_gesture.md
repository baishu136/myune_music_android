# Android 368：符号时序、无焦点入场与动感手势隔离

日期：2026-10-05；源码 `1.0.0+368`，显示 `1.0.0-android.368`，ARM64 split versionCode `2368`。基于实际367工作区继续，保留361–367的全部未提交成果；未提交、推送或发布GitHub。

## 查明的问题及修复

- 主页正文/标题共享时长从600ms改为300ms；性能忙碌窗口从680ms改为380ms。保留源/目标端点衔接、按需构建、已访问页State、直接跳过中间页及底部磨砂，不改变曲线或其他页面时长。
- 普通LRC的连续纯符号被当成一个标点，测试句中五个星号仅分到34.99ms。现在连续符号/符号词采用既有可见字素长度的次线性权重；单个普通标点仍为短拍，单星号及Unicode符号也参与推进。只改变**估算**时间，不改真实词元边界、行时间戳、高亮视觉补偿或上浮参数。
- 列表将播放器的`active=-1`夹为0，错误制造首行焦点。显示焦点现在保留-1；只有滚动几何锚点用0。前奏seek从第一行起查找前驱，无前驱保持-1，刷新和锁定释放均支持该状态。
- 返回歌词页的隐藏准备阶段立即清除旧浏览框、时间和相关定时器，避免旧240ms退出重放。正常纵向浏览仍有原渐隐和3.5秒回中，不改正播行无跳转提示规则。
- 原始pointer-down就进入浏览，双击暂停和横滑切歌会令动感行间偏移瞬间归零。现在按下只冻结列表追踪；垂直ListView赢得拖动手势后才进入浏览。移除播放页横滑开始时的提前recenter；真正换歌在原淡出完成后重置新内容，保留既有单列表淡出/淡入。

生产改动仅`mobile_shell.dart`三处连接/窗口、`home_tab_viewport.dart`共享时长、`mobile_lyrics_list.dart`状态边界和`synthetic_karaoke_timing.dart`估算权重。没有重写绘制引擎，没有每帧新增排版、缓存或图片生成；流体、主题、字体、逐字高度/跟随、三档行滚动均保留。
