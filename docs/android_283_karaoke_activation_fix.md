# Android 0.9.9+283 逐字歌词生效修复

## 原因

开启旧有“高亮歌词”选项后，活动歌词行会提前走整行纯文本分支，逐字歌词即使已开启也无法创建逐字富文本和播放位置监听器。

## 修复

- 逐字歌词开启且当前行具有有效逐字时间，或范围选择“全部”时，逐字绘制拥有更高优先级。
- “高亮歌词”仍决定已播放文字的高亮色，但不再禁用逐字推进。
- 关闭逐字歌词后，旧有整行高亮行为保持不变。
- 新增普通 LRC、“全部”模式、“高亮歌词”同时开启时的组件回归测试，并验证播放位置变化会更新逐字分段。
