# 309：逐字动画帧节奏与缓存连续性

## 检查发现

- 308 的视觉时钟每帧对“当前时间到目标时间”整体插值，正常播放推进也被低通滤波，产生稳定滞后；普通负向校时超过 70ms 时还会直接回退视觉时间。
- 父组件重建会创建新的 CustomPainter，原委托中的字形、段落和选择框缓存未沿用，增加播放期间重复排版的机会。
- 上述是代码层面可确认的问题，不等同于已证明全部真机卡顿均由这两处造成。

## 修改

- 根据用户补充的快速歌词高亮不及时，取消短词结束端最多 180ms 的延迟。仅允许开始端不超过 60ms 且不超过词时长四分之一的轻微预热；词末和最后一个字在原时间戳上完成高亮。

- 正常帧先按实际经过时间推进，只对时间误差进行修正；每帧修正限制为正常步长的正负 8%，防止普通校时使字形倒退或停顿。
- 保留真实跳转和较大时间不连续时立即同步，暂停时直接跟随实际进度。
- 文本、时间段、字体、对齐、方向、缩放与语言未变化时，沿用旧绘制委托缓存；宽度变化仍由布局检查重新建立缓存。
- 保留 308 的不透明字形遮罩、局部渐变及逐字上浮，没有回退基线，也没有重新叠加一份底字。

## 自动验证

- 歌词与更新记录专项测试包含真实字体亮度、文字可见性、边界及跳转回归。
- 新增 40–519ms 短词及末字按时完成高亮的回归检查。
- 新增 60/120Hz 正常时间推进无滞后，以及正负校时不会反向或停顿的测试。
- 全套 232 项测试通过；最终时钟微调后再次通过 70 项专项测试与修改文件静态检查。
- 移除旧的“小误差则不推进”分支，避免普通校时恰好抵消一帧时间时出现停顿。
