# 0.9.9-android.277

## 动态背景回退

- 移除 276 版新增的封面纹理流体背景、纹理缓存和第二套 Fragment Shader。
- 设置恢复为“模糊封面”和原有“流体色彩”两项，原流体背景的取色、节奏联动和质量档位保持不变。
- 已经保存为 `coverFluid` 的测试版设置会由现有安全解码逻辑自动回退到“模糊封面”。

## 首页歌曲列表动画

- 动画不再仅以歌曲缓存非空作为启动条件，同时等待音乐库载入状态完成。
- 音乐库列表先完整绘制一帧，再等待一个短暂稳定窗口后将控制器归零并播放 720 毫秒动画，避免动画在启动遮挡或密集数据通知期间提前结束。
- 动画开始时登记“已领取”，完成后登记“已完成”；页面中途重建直接显示最终状态，避免重复播放。
