# Android 360：地色 + 双色斑 + 环境色分层流体背景

日期：2026-10-04。基线为实际 `1.0.0+359` 工作区；发布版本 `1.0.0-android.360`。保留已有未提交成果，尤其未改动 359 的中文/日文歌词连续跟随、桌面歌词及其他页面。

## 核对结论

359 的实际 Shader 已是 358 的 Power-Softmax 四光场归一化，不是线性加法。此前 Screen 叠加已被替换；本轮依照用户新方案，进一步废弃四场归一化和权重总和除法。用户报告的 78%→14%不是本轮自行实测，不能作为当前 APK 的像素统计，也不能仅靠录屏逆向确认 Salt Player 内部实现。

旧 `baseColor` 在 358/359 只作为兼容 Uniform 存在，未实际参与绘制。此外旧控制器把有效时间乘以质量档位频率和音频能量，直接在 Shader 写 `.065` 无法得到稳定的 96 秒周期。这两个问题一起修正。

## 新架构与默认值

### 单通道遮罩合成

固定次序：`baseColor` 地色 → `third` 弱环境色 → `second` 色斑1 → `fourth` 色斑2。每步只做 `mix(previous, pigment, mask)`，无加光、权重归一化、额外纹理、模糊滤镜或 saveLayer。

每个色斑采用椭圆归一化距离平方及 `1-smoothstep(.10, 1.0, d²)`：核心遮罩为1，有限边缘柔和收敛，不把所有颜料平摊到全屏。两个色斑半径分别为 `(.62,.78)`、`(.55,.70)`，不同相位对角巡航；环境半径 `(1.10,1.0)`、最大遮罩 `.16`，在色斑下层，不能漂白不透明核心。旧 `first` 与 glow Uniform 仅保留48-float ABI/元数据兼容，已无第四个光源；实际渲染测试验证改动 `first` 不影响任何像素。

地色现在直接消费 Dart 提取值。暗角仅 `.98–1.0`，不再将中心乘以1.05；原 dim 限幅 `.60`、最高15% RGB衰减、静态亚色阶抖动及不透明输出保留。核心RGB在 dim/暗角之前保持原颜料值；不能将输入HSL饱和度范围等同于最终全屏HSL百分比。

### 慢时钟与大尺度形变

有效时间改为可见、前台、非路由/性能阻塞期间的实际秒数，不再乘旧5.5/6.5秒质量档位频率或音频能量。Shader 唯一角速度 `.065 rad/s`，周期 `2π/.065 ≈96.664s`，半周期约48.332s。所有档位只改变绘制调度（24/60/120上限），不改变轨道配速。原有单帧50ms限幅保留，因此长阻塞不以大跳跃补时。

域扭曲空间系数1.6、1.8、2.0、2.2，双层幅度 `.10/.055`，不使用高频条纹。时域仅整数谐波，统一96.664秒回绕避免闪变。音频能量只影响原有平滑空间形变/轨道幅度包络，不再改变相位速度；减少动画、后台/隐藏路由及恢复保护仍有效。暂停音频后的环境背景继续缓慢运动，区别于歌词媒体时钟。

### 两极取色与稳定角色

继续使用64×64解码、worker直方图、有界64项LRU和去重请求；白色高光过滤、真实暖色面积保护、黑白与单色防伪彩保留。所有新增分析仅在每张封面取色阶段执行。

- 暗色封面：既有加权明度分类小于 `.28` 时，地色明度为最暗保留颜料明度的8%，上限 `.012`，纯黑仍为黑；取消“鲜艳暗色封面”被 `.35–.55` 主色强制提亮的问题，不凭空添加亮色。
- 鲜艳非暗封面：色斑1选择真实占比和彩度显著的颜料；色斑2按实际颜料与主色的色相距离、彩度和占比分数选择对比色（占比至少1%，不凭空合成互补色）。两色输入HSL饱和度限定 `.75–.85`，明度 `.35–.55`。单色封面允许两斑同色，不强造第二色。
- 非暗地色取主色同色相、半明度，限幅 `.12–.26`，保留厚重而非中央黑洞；真实暖色仍在环境槽。
- `layeredRolesLocked` 随插值、相等性及哈希传播，阻止最近色槽重排将色斑换成环境灰色。650ms切歌插值及中途重定向的起点连续性保留。

## 验证与限制

先补测试，359 基线出现4项预期失败：暗色地色不够深、第二色斑/角色不满足要求、时钟仍受配速影响、实际 Shader 不符合分层标量公式。实现后相关41项通过，全量 Flutter **464项通过、1项既有截图导出跳过**；最终静态分析无问题；APK审计工具6项单测通过，`git diff --check`通过。

实际 `FragmentProgram` 96×160渲染逐像素抽样与独立分层标量公式对照误差≤2个8-bit色阶；验证两个独立核心RGB、地色修改确实影响背景、元数据不再产生第四光源、单色保色、黑白保护、dim、周期回绕与相邻帧连续。新控制器测试覆盖不同档位和交替音频能量的一秒实际时间推进、后台冻结。原有60/90/120Hz调度、650ms快速重定向及缓存失效回归继续通过。

合成粉红/青绿/暖黄样本，经实际取色后在0/24/48/72秒渲染的平均HSL饱和度分别约 `.5829/.4805/.5467/.5597`。另一固定颜料、静止轨道网格的新分层均值 `.5773`，同输入旧Screen数学诊断 `.5276`；不是359 Power-Softmax的真机对照，不是《Cupid》原封面，不能用这些结果宣称全屏75%或所有封面更高彩。

线性遮罩混色在互补色交界仍会降低彩度，650ms切歌RGB插值也可能出现低彩中间态，因此不承诺数学上“零灰”或所有相位100%保持75–85%。不透明核心不参与全场均值；本轮杜绝的是全场光能累加，而不是取消自然颜色过渡。黑白封面不会为了饱和度指标染色。

本轮 ADB 未发现连接设备，**未做真机安装、录屏、Profile/Perfetto、GPU/功耗或实呈现120fps验收**。软件渲染PNG已抽查，属于合成样本技术检查，不替代真实封面、全屏长周期观感或帧预算验收。去掉pow/exp混权计算属于理论开销减少，没有描述为实测性能提升。
