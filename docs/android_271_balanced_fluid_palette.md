# 0.9.9-android.271

## 动态背景

- 取消按封面颜色占比决定流动色域面积，四个低频颜色场改为等权混合。
- 限制各颜色场中心的移动范围，使封面存在多种主要颜色时，它们不会整体移出屏幕或被主色吞没。
- 根据封面加权平均饱和度与明度区分鲜艳、暗沉风格；鲜艳封面保留更高饱和度，暗色或低饱和封面不再被强制提亮。
- 允许纯黑作为有效的动态背景颜色，纯黑与彩色可以共同参与柔和流动。

## 切歌过渡

- 新调色板先与当前调色板进行四颜色槽的最短距离匹配，减少颜色因返回顺序变化而绕路变色。
- 调色板过渡由 1100 毫秒延长至 1700 毫秒，并在 Shader 中使用五次平滑曲线，使起止速度和加速度都连续。
- 连续快速切歌时仍从当前画面快照继续过渡，不会先跳回旧封面颜色。

## 性能约束

- 仍只绘制四个颜色场，不增加 Shader 纹理采样、颜色场数量或逐帧取色。
- 封面占比与风格分析只在封面取色完成时执行；颜色槽匹配每次切歌最多比较 24 种排列，不进入逐帧路径。
