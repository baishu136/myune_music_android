# Android 254：控制区、流体背景与歌词字号滚动优化

日期：2026-09-11

## 改动

- 仅移除截图标注的主播放控制区与底部工具栏实时模糊，保留原半透明面板外观。
- 均衡器等未标注区域继续使用 253 版共享背景采样和 220 毫秒模糊淡入过渡。
- 流体背景三个质量档位的运动周期由 28 / 24 / 20 秒缩短为 26 / 22 / 18.5 秒，刷新率仍为 24 / 30 / 60 FPS，避免用增加绘制帧数换取速度。
- 歌词字体排版变化时停止旧滚动速度和弹性脉冲，按新行高将当前歌词重新锚定到视口高度 40% 位置，避免连续调大字号时来回抽搐。
- 若排版变化时用户仍在触摸歌词，重定位请求会保留到自动跟随恢复后执行，不抢夺手势。
