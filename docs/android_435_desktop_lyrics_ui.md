## 功能

- 正播歌曲标题和歌手统一冰蓝色 `#70B9D6`，覆盖主页/底部选歌列表、桌面列表与队列、迷你播放器、播放页标题和全屏切歌提示。共享列表标签保留120ms颜色过渡，主题换色不再改变正播标签的目标颜色；歌词文字高亮不改。
- 长按收藏弹窗使用本地草稿，勾选、撤销和新建歌单都不写入实际歌单。完成、返回或点遮罩关闭后，等待浮窗退出动画与路由释放完成，再通过既有歌单API按最终意图执行；反复切换回原状态不写入。执行时重读真实歌单，跳过被删除的歌单/已满足的目标。暂存状态显示预计歌曲数和封面，仅改动的条目复制路径，保留实际曲库、播放来源及原有持久化路径。失败关闭后提示检查，不显示虚假成功。
- 桌面自动字号新增最大显示行数1～6（默认3）、最小字号8～40（默认12，实际不超过所选字号）。原生排版只在文本/宽度/样式变化时拟合字号，允许换行；下限仍放不下时按最大行数省略，不缩成不可读的微小文字。Flutter设置预览也按多行及最小字号约束。
- 桌面歌词切换动画默认开启，可独立关闭并保存。使用两层提前排版的原生文字，保留描边、逐字高亮、对齐和用户透明度；以缩放/透明度交接，不逐帧修改字号或重新排版。退场在下一行时间前200ms开始、200ms完成；入场提前180ms开始、220ms完成，两者透明度均在各自动画80%时到位，缩放有轻微弹性缓冲。整组原文/译文同步运动。真正逐字高亮仍使用原时间戳，不提前修改歌词或音频。
- 延用已有播放时钟和歌词视觉补偿，新增稳定的歌曲/seek身份，切行不重置媒体时钟。暂停冻结、恢复/倍速继续，seek/换歌直接重定位；相同时间点交接时复用已准备的新层。减少系统动画时直接显示，不强制播放过渡；关闭动画后跳转仍保证主层可见。只有交接窗口逐帧调度，其余睡眠至下一边界；已有进度流最多约800ms稀疏校时，关闭桌面歌词时不新增后台轮询。
- 用户确认的横向选项范围统一为右侧抽屉：对齐、同时间戳行数、滚动效果、逐字范围、歌词源、主题模式、播放页背景样式/封面大小、均衡器预设等，共15处调用。主页导航与底部选歌标签保留。菜单宽度不超过屏宽82%/344，按选项数量限制高度；外圆角28、选项边框8。播放页仍复用原有5/7模糊和28%/10%表面透明度，普通设置沿用主题表面，不改变背景参数。选中后关闭抽屉再提交选项。
- 主题配置页卡片底色与表面染色透明，背景预览固定黑色遮罩40%，保留原模糊配置，不改用户保存的主页遮罩值。有背景图时用浅色文字；图片失败回退深色底，普通抽屉标题按实际表面明暗显示。
