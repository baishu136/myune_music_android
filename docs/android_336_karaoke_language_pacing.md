# 336：逐字歌词语言配速与英文字母上浮

日期：2026-10-01。对照工作目录中的三组录屏；`参照1–3.mp4` 与 `salt1–3.mp4` 内容重复，第一组录屏的文件名与实际播放器对应关系相反。工程基线为 `0.9.9+335`，保留原有未提交成果。

## 修复

- 普通 LRC 的合成歌词原先把英文单词强制作为一个绘制单元：词内虽有连续扫光，整词却同时上浮。现在对可安全拆分的字素建立独立缓存、时间与上浮姿态，使字母依次跟随高亮。连字、组合字符、斜体及过长词元仍按完整排版片段回退，避免破坏字形。
- 合成时间轴区分文字比例。中文、日文、韩文的字素前段权重较轻，句尾权重较重，整句使用较短的演唱窗口并最多提前 80 毫秒预热首字；英文使用较长的窗口和更接近字母数的词权重。中西混排按可见词元比例插值；标点使用较短的停顿权重。
- 播放时钟在 30 毫秒内保留小幅平滑；30–200 毫秒偏差快速追赶且不倒退；超过 200 毫秒按位置跳变处理。显式 seek 原有路径不变。
- 真实逐字词元时间戳原样保留，翻译行仍不参与逐字高亮。

这些配速是普通 LRC 缺少逐字时间戳时的视觉估算，不能从行时间戳推断歌曲的真实咬字时间。不同歌曲可能仍需要真实逐字歌词或用户偏移设置。录屏未提供可直接导入的同源音频与歌词文件，因此没有宣称与人声达到毫秒级同步。
