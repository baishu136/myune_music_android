# Android 287：逐字歌词统一非当前行与严格字形遮罩

日期：2026-09-14

## 修改

- 开启逐字歌词后，所有非当前播放行统一采用逐字歌词的未播放颜色。
- 因外发光透明度跟随文字颜色，所有非当前行的外发光强度也保持一致。
- 当前播放行仍保留已播放、当前推进与未播放三种视觉状态。
- 已完成的词合并成一个缓存文字层绘制；正在推进的词使用独立字形文字层。
- 不再使用整行高亮文字套入词框的方式，避免斜体、连字和字形外伸误染相邻字符。
- 当前词的柔边遮罩继续限制在词框与组件绘制区域交集内。

## 性能

- 已完成词组合层只在跨过新词时重新生成，普通帧直接复用。
- 当前词字形层按词缓存，播放进度仍只触发 `CustomPainter` 重绘。
- 没有增加歌词列表重建、逐词 Widget 或额外滚动控制器。
