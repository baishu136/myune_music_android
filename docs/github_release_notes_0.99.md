## 新功能

- 新增点击歌词跳转框跳转，短歌词的有效触摸范围自动延伸至三行区域。
- 新增歌词外发光设置，发光颜色和透明度跟随歌词行。
- 桌面歌词改为可展开设置，补齐预览、颜色、字号、描边及锁定选项。
- 歌手与专辑页新增按数字、符号和首字母分组的索引查看方式。
- 歌手、专辑页面新增列表、网格和字母排序切换。
- 置顶歌曲、歌手和专辑可独立显示在内容最上方。
- 音乐库、歌单、歌手和专辑新增各自独立的歌曲排序入口。
- 音乐库与歌单支持长按打开页面专属排序菜单。
- 歌单页将新建歌单与导入文件拆分为独立入口，并保留原有导入能力。
- 播放页顶部新增已播放进度、剩余秒数和歌曲总时长显示。
- 新增默认歌词列表过渡动画及距离歌词行模糊效果。
- 常规设置新增更新日志和可展开赞助说明。
- 赞助区支持微信、支付宝二维码并排显示及保存到系统相册。

## 修复

- 修复进入播放页后立即下拉歌词时可能被强制拉回正播行的问题。
- 修复点击跳转后先滚到目标上一行再返回目标行的问题。
- 修复歌词跳转与切换封面页手势冲突导致误切页的问题。
- 修复跳转框只有点击中间位置才能触发的问题。
- 修复点击歌词页无法返回封面页的问题。
- 修复开启歌词外发光后滚动歌词明显卡顿的问题。
- 修复开启高亮歌词后歌词页与封面页互切卡顿的问题。
- 修复歌词外发光启用时从歌词页切换至封面页卡顿的问题。
- 修复歌词放大后顶部与两侧绘制边缘被截断的问题。
- 修复最上方歌词在下一行动画开始后过早消失的问题。
- 修复歌词动画过程中歌词可能被背景层遮挡的问题。
- 修复播放页背景准备阻塞页面进出动画的问题。
- 修复通知栏及播放页中特殊字符、多语言 WAV 文件名乱码的问题。
- 修复置顶标志与置顶文字重复显示的问题。
- 修复歌词设置中多个无实际作用或重复选项的问题。

## 优化

- 优化歌词外发光绘制缓存，使滚动和高亮进度更新的性能波动更平稳。
- 优化高亮歌词的重绘范围，减少歌词列表无效重建。
- 优化歌词弹性滚动、跳转定位和手动浏览后的跟随恢复。
- 降低默认歌词滚动动画速度并柔化位移曲线。
- 优化歌词顶部与底部渐隐范围、过渡区域和柔和度。
- 侧边歌词尽量靠近屏幕安全边缘，同时保留完整文字显示空间。
- 歌手与专辑网格统一采用 312 像素封面并使用紧凑排列。
- 优化歌手、专辑和歌单的分组标题、置顶区与内容间距。
- 移除歌手与专辑页顶部渐隐，为歌单歌曲列表增加主页一致的渐隐。
- 优化主界面各页面顶部排序按钮的位置、点击和长按交互。
- 移除通知栏播放器进度条，简化系统媒体控制布局。
- 重新按功能和视觉优先级排列个性化设置。
- 整理歌词设置名称、说明位置及桌面歌词选项注释。
- 移除播放页模糊背景、始终显示专辑名称等重复设置。
- 锁定背景参数的渲染对象并延后非关键处理，保持封面加载速度。
- 优化播放页封面恢复、背景切换和图片主题稳定性。
- “其他”调整为常规页底部普通字号选项，并沿用透明背景。
- 修正赞助区发布次数与有效改动数量的统计口径。
