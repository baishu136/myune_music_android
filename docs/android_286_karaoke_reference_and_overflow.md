# Android 286：参照视频继续优化逐字歌词

日期：2026-09-14

## 对比素材

- 参照：`1 (3).mp4`
- Myune 285 实机录制：`2 (3).mp4`

逐帧对比覆盖了单词推进和约 9.4–10.0 秒的整行切换。参照效果的重点是短词快速响应、长词保留可读推进时间，当前行保持清晰，邻近行逐级降亮；高亮仅发生在字形内部。

## 调整

- “全部歌词”生成的逐字时间轴不再把每个词机械等分，改为按可见字符数量进行次线性加权。
- 中文等单字型歌词仍保持均匀节奏；较长英文单词获得更长但受控的扫光时间。
- 高亮进度使用连续线性推进，柔和感由字形内部的羽化前沿提供，减少词首词尾的黏滞感。
- 逐字绘制忽略词首、词尾空白，避免亮区延伸至单词间隙。
- 移除超出字形的额外高亮光晕；部分词图层与已完成词裁剪均限制在实际字形及组件边界内。
- 适度降低相邻歌词亮度，强化参照视频中当前行聚焦、旧行退场的层次。

## 性能

- 保留 285 的连续视觉播放时钟和缓存文本布局。
- 每帧只重绘当前逐字高亮层；没有新增逐字组件、额外布局或逐词缩放动画。
- 去除高亮光晕后，当前词每帧的离屏图层面积更小。
