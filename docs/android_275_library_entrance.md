# 0.9.9-android.275

## 首页歌曲载入动画

- 将一次性动画状态拆分为“已领取”和“已完成”。
- 歌曲首次准备完成后，当前音乐库页面先领取动画，再在下一帧播放 720 毫秒的错峰淡入与上移动画。
- 领取动作不再提前移除当前页面的动画控制器，因此首次启动动画能够正常显示。
- 动画完成后才关闭后续动画；如果启动期间页面被销毁并重建，新页面直接显示最终状态，避免整组歌曲重复载入。

## 流体背景实现摘要

- 从封面异步提取并缓存主要颜色，按封面明暗与鲜艳程度进行筛选和归一化。
- 使用四个稳定颜色槽，并在切歌时对新旧调色板进行颜色距离匹配与 1700 毫秒平滑插值。
- 由 Flutter Fragment Shader 在 GPU 上合成多层低频形变色域，控制器只更新时间、运动幅度和调色板参数。
- 音频低频能量经平滑和限幅后调节运动速度；暂停播放时仍以基础速度流动。
- 页面切换、拖动等关键交互期间可暂缓着色器帧，恢复后使用连续相位，避免跳色和闪烁。
- 着色器尚未就绪、系统要求减少动态效果或着色器不可用时，自动显示同步渐变兜底背景。
