# Android 290：歌词跳转边界与逐字上浮

日期：2026-09-14

## 修复

- 手动浏览歌词时暂停逐字歌词的候场/离场位移，使跳转目标文字和高亮框始终使用同一行坐标。
- 解决大字体或多行歌词在跳转框底部溢出，以及时间标签与偏移后歌词发生视觉冲突的问题。
- 退出浏览后恢复逐字歌词的正常换行位移动画。

## 优化

- 为当前正在高亮的词增加正弦上浮曲线：开始时保持原位，高亮中段达到最大上浮，完成时平滑回到原位。
- 上浮幅度根据字形高度计算并限制在 1.5—5 像素，兼顾普通字体与大字体。
- 高亮绘制安全区向上扩展，水平方向仍严格限制在当前词框内，避免重新引入相邻字形溢出。

## 性能

- 上浮只改变 `CustomPainter` 的绘制偏移，不增加 Widget、布局或文字测量次数。
- 正弦曲线只在已有逐字重绘帧中计算，不新增动画控制器或 Ticker。

## 验证

- 覆盖逐字上浮起点、中点和终点曲线。
- 覆盖手动浏览状态下跳转目标位移归零。
- 执行静态分析、完整 Flutter 测试与 arm64 release 构建。
