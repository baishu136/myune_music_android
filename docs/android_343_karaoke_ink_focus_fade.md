# 343 逐字墨迹边界与高亮入退场（候选基线）

2026-10-02，基于实际 342 工作区，保留原有未提交成果。此轮构建 ARM64 Release；新追加的主页/切歌/预备行需求继续在 344 开发。

## 根因与修复

- MiSans W800 的 y/g/p 墨迹超出 TextBox 和折行分割线。原先从完整段落裁矩形，尾部属于邻字/下一折行，文字微浮后发生分离；单纯增大 saveLayer 范围无效。
- 缓存完整白色段落覆盖率与彩色墨迹身份图，着色器按身份取完整墨迹，并在身份解码后做四邻域插值。白色原始覆盖率独立于身份颜色，防止彩色文字抗锯齿的覆盖率差异使边缘变细。两图合计不超过 4MiB/行；仅当前、退出、下一行和一个预热槽保留缓存。完成高亮的字形连带超出 advance box 的墨迹全部着色。
- 普通 CJK/西文只准备有限数量的整段排版，不按每个字/词排整个段落。复杂连写、组合与彩色字形保留完整原生词/折行片段回退；异步缓存未准备好时原文完整弱化显示，失败才在 paint 外准备额外原生词元蒙版。
- 旧退出行把未唱色/翻译色立即改为白色，外层透明度尚未退出。现在逐字行统一自行合成墨迹透明度：未唱原文保持暗底 .36（浅色模式灰色 .68），翻译始终为其 60%；已唱高亮独立执行 240ms 入退场，不交换成白色。正常进入渐入，明确 seek 定位到端点。
- 等待圆点使用 500ms 媒体时间提前触发、240ms 实际时间收拢上飘消失；实际切行不重启退出，暂停时不触发提前消失，seek 取消旧退出。

## 验证与限制

- 完整测试 376 通过、1 项既有可选导出测试跳过；随后补充完成高亮覆盖 overhang 测试，针对像素组 9 项通过。静态分析无问题。新增真实字体 own-ink、专属墨迹、DPR 1/3 半像素移动、折行/复杂文字、实际翻译像素不闪白、入退场强度与提前退出/暂停/seek 回归。
- V2352A / Android 15 / ARM64 Profile / Impeller Vulkan，隔离包 `com.myune.music.karaokebench`，不访问正式曲库，无音频，4秒预热后36秒压力采样，覆盖三档滚动、白/主题色、翻译、快速跨行、长词与等待。基线342与候选343使用同一 fixture。首次候选2160帧，Raster 超16.67ms 共6帧（默认白3、默认主题色1、动感白2，其余0）；基线2170帧也有6帧超预算。因此不能宣称性能提升或全部满帧。
- Display API 报120Hz，但 dumpsys 显示实际 renderFrameRate=60，时间戳为约16.67ms。尝试用户首选120模式仍被系统限制为60，已还原首选模式为空。**120fps未验证，满帧验收未通过，不正式提交验收。** 后续344继续真机复测；不能把公式连续或单元测试通过当作观感/帧率结论。
