# Android 416：音频输出与统一歌词同步

基于 415 未提交工作区，保留该轮歌手/专辑页面及音效回退成果。本轮版本为 1.0.0+416，正式 ARM64 versionCode 2416；不提交、推送或发布 GitHub Release。软件内更新日志仍按实际 GitHub Release 归并，413～416待下次获授权发布时合并。

## 已集成的功能

- 设置→播放→音频输出设备与歌词同步；歌词设置内也可进入校准。Android AudioManager 事件动态列出系统提供的真实输出端点，可查看名称、类型、采样率、编码、声道及系统混音器能力。空能力不伪造规格。
- 默认设备ID为0，跟随系统自动路由。应用内选择使用音乐输出的 AAudio 设备ID，不进入通信模式、不启用 SCO。通话/内部混音等受限制端点使用系统选择方式。API34及以上优先系统媒体输出选择器，其余使用系统音量/声音面板。
- 选择请求与实际回执分离：只有应用自己的单一有效 AAudio 流、真实设备ID和当前连接清单一致才标记实际输出。多流、不明状态、断连或后端回退时不推测当前设备。失败尝试恢复普通自动输出；不重建播放队列，不跳转歌曲进度。
- USB 高级模式仅在实际 USB 输出存在时提供。标准模式保留原音效；系统提供匹配的 API34 Bit-Perfect 混音器格式时，可请求原采样率/整数PCM/声道配置，并暂时旁路均衡器、音效、增益、倍速、软件音量和播放恢复参数。退出后恢复最后的用户配置，不永久改设置。开启前明确提示软件100%与硬件音量控制。
- Bit-Perfect 生效显示要求源PCM、应用流、系统偏好、硬件格式一致，以及音效/音量/倍速的实际读取确认；严格端到端位流始终明确未经外部测量。浮点源、不匹配格式、未知硬件回执不冒充严格 Bit-Perfect。当前 AAudio 后端不会直接输出 packed24，32位PCM可承载相容的24位音源；实际格式以系统回执为准。
- USB独占采用 Android AAudio 独占共享模式及低延迟请求，必须读回实际 sharingMode=exclusive，系统降为共享时回退标准模式。它不是直接接管 USB 接口的独立 UAC/libusb 驱动，不承诺绕过所有厂商音频实现，也不将普通USB流标作独占。无 Root、系统分区修改、USB接口强制占用或常驻设备轮询。
- 热插拔、系统路由变化、原生流开关、混音器偏好变化均走事件回调。系统撤回专用输出、所选端点断连或初始化失败时恢复标准路径；恢复过程各清理步骤独立尝试，避免前一步失败阻止音效还原。进程退出依次恢复处理参数、撤销偏好并释放原播放器；异常进程终止由Android回收音频资源。

## 同步规则

- 全局默认0ms，设备偏移范围±2000ms，整数滑块和±1/10ms微调；正数让画面延后，负数让画面提前。设置实时预览并保存，支持恢复默认及重置。歌曲独立偏移±10000ms，独立于全局、设备和原文件时间戳。
- 一条共享视觉时间轴供正播行、逐字、跃动、缩放、行滚动、译文、播放页和桌面歌词使用。歌曲进度条仍使用原始播放时间。按歌词跳转时做逆转换，不把视觉偏移写入音频进度或文件。
- 设备补偿按墙上时间乘实际倍速，歌曲偏移按媒体时间；两者只各应用一次。沿用 mpv 已利用播放头校正的时间，不再扣除 AAudio 本地排队时长，不把蓝牙猜测值当作真实声学延迟。
- “自动时间轴稳定”使用单调投影平缓修正小抖动，大幅跳转/显式seek立即定位；暂停冻结、恢复和实际倍速切换重新取基准。无新增逐帧播放器轮询、独立逐字计时器或全曲重排。设备配置变更主动更新行焦点和绘制时钟。
- 设备身份优先系统提供的可靠地址或唯一USB序列号的散列；不按重名产品名称共享配置。匿名/有线端点使用本次连接身份，断开即失效。USB仅在物理对应唯一时允许可选授权读取序列号，拒绝不影响标准播放；不申请音频接口控制权。蓝牙标识权限受Android限制时可按需申请，无法可靠持久识别时明确只保留本次连接配置。

## 原生桥接与可复现构建

保留现有 libmpv 解码器、播放器状态、媒体会话和队列。自己的 `libmyune.so` 只转发系统 AAudio 并读取该播放器实际打开的流，不触碰PCM、不包装数据回调。数据回调会用到的函数地址在库初始化时缓存，避免回调内额外符号查询、分配或锁。

Gradle 在生成目录中把已固定SHA256的 libmpv 动态加载名 `libaaudio.so\0` 等长替换为 `libmyune.so\0\0`，源目录三份原始库保持不变。逆替换必须得到上游精确SHA；未知输入构建失败。APK增加自有桥接库，其余解码器保留。指定ARM64时插件也只构建对应ABI。JNI管理类以Keep保护，避免Release混淆破坏回调。

参考：[mpv 0.41 AAudio实现](https://raw.githubusercontent.com/mpv-player/mpv/v0.41.0/audio/out/ao_aaudio.c)、[Android USB混音器属性](https://developer.android.com/media/platform/improve-audio-playback)。上游许可及原始依赖声明保留。
