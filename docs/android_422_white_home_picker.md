# 422 浅色主页纯白底色与选歌控件正播标签

2026-10-24；1.0.0+422，ARM64 versionCode 2422。完整保留421及既有未提交成果，本轮不提交、推送或发布GitHub Release，应用内日志仍为最后实际发布的412。

## 修改

- 浅色主页在启用动态/手动主题色时也统一采用纯白默认底色。主页局部的Scaffold、Canvas、各级surface、默认卡片、顶部与导航表面设为白色，关闭表面染色；主色、文字和选择状态色继续沿用当前主题。禁用主页主题色时仍使用原中性前景，原有自定义图片/封面背景设置继续按设置显示。
- 处理只发生在HomeThemeScope内；深色主页直接使用原主题，切换主页禁用主题色选项继续保留页面State。纯白主题按源ThemeData变化缓存，普通重建不重复生成。被推出的播放页不接收主页白底覆盖。
- 播放页底部选歌控件的歌曲标题、歌手/专辑副标签在正播时采用主题主色。音乐库、歌手、专辑、搜索及歌单歌曲共用的queueActions条目按歌曲路径匹配当前歌曲，不再要求其歌单上下文与实际播放上下文相同；普通非queueActions列表保留原上下文判断。切歌后新旧条目状态随现有监听更新，暂停仍标识当前歌曲。
