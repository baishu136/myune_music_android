# Android 302：参考视频宽渐变与逐字波浪

## 可见差异修正

301 的颜色进度虽然已经连续，但羽化仍发生在单个字形的小范围内，实际只有数像素，真机观感与上一版接近。本版重新按照参考视频的可见范围处理：

- 高亮边缘扩大为约一至两个字符宽，渐变可同时覆盖相邻字符。
- 当前词的所有字形共用同一个全局渐变着色器，不再在字符边界重新开始渐变。
- 逐字上浮幅度由排版行高的 8% 调整为 12%，并限制在 2.5—8 像素内。
- 继续使用两端零速度的 S 型曲线及 Unicode 字素拆分，保持起落柔和并避免组合字符损坏。

## 性能

字符范围、排版框及实际宽度均在布局阶段缓存。动画帧只更新渐变前沿和字形位移，已播放与未播放歌词仍走合并缓存路径。
