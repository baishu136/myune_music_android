其余行按实际尚需移动的距离决定节奏：距离越长，起步越缓、前段停留越明显，后段逐渐加速，到目标前进入一段柔和越位再回落的缓冲。没有人为增加起始静止等待；位移首帧仍恰好抵消列表跳到目标的布局变化，不用放大初始抵消量制造跳位，也不靠扩大行距冒充运动距离。

独立轨迹的推进段为3.2～4.8次幂，时长320～900ms；越长则幂次和时长增加。完成72%距离后接五次缓冲，衔接位置、速度及加速度连续，结束三者归零。48/192/600逻辑像素的静止起步模型中，越位约原位移7%～16%，总路程超过原位移114%，较此前轻微回弹增加可见运动幅度；这是模型范围而非所有真实歌词行的固定越位比例。连续短句不重启错峰等待，保留速度并缩短推进段；反向目标保留交接速度后再转向。

两种速度曲线混用时，上方慢起步行可能与快速入场的正播行挤压。新增列表局部波形协调，只对实际可见范围内的整行做平滑避让：用现有行高扣除最大缩放后的上下内边距，保留正文/译文的最大绘制高度。接近邻行时连续收窄相对位移，正播行始终不受改写；必要时避让优先于自由的慢起步曲线。肩部初始宽度受当前真实间隙限制，随后180ms以首尾零速/零加速度展开，并把宽度变化纳入行速度，避免密集换行后贴靠行解除约束时突然换速；中途换目标不重新挤动首帧。正常字号与多行混排均不靠每帧重新测字解决碰撞。

继续共用原有帧时钟；没有新增行级Ticker或Timer。可见行的运动在同一个时刻只统一采样一次，成员变化时才排序，帧内不创建列表或轨迹对象；缓冲段为多项式求值，推进段每行一次幂运算。错峰等待或位置不变时不重复通知行重建；参与避让的非正播行保留监听到整波结束，以免邻行后续运动时丢失约束，结束后释放原时钟计数。由此仍有额外的线性协调运算和更长动画时段，未以无设备条件下的模型测试宣称CPU/GPU或耗电下降。
