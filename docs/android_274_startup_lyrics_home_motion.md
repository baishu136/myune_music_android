# 0.9.9-android.274

## 启动歌曲载入动画

- 歌曲列表首次具备内容时立即登记入场动画已经开始，不再等 720 毫秒动画结束后才登记。
- 启动数据通知导致页面重建或暂时销毁时，新页面会直接显示最终状态，不会重新播放整组歌曲入场动画。

## 歌词滚动稳定性

- 新增“可见动画”交互阶段，默认歌词滚动期间每帧续期，弹性回弹触发时覆盖完整回弹时段。
- 该阶段暂停封面预取、调色板计算和维护写入等可延后任务，避免与歌词布局、位移及模糊绘制争抢帧时间。
- 流体背景不受可见动画阶段限制，歌词滚动时仍保持原有背景流动，不产生视觉冻结。
- 用户拖动、页面切换等更高优先级状态不会被歌词动画降级。

## 主页切页

- 点击底部导航时在首帧构建前进入过渡保护，手势切页在按下时提前进入保护。
- 跨越两个及以上页面时先无动画定位到目标相邻页，只对最后一页执行 320 毫秒过渡，避免连续构建所有中间页面。
- 相邻页面切换及左右滑动的现有动画方式保持不变。
