本次重点改善后台播放、歌词显示和界面操作体验，汇总上次发布以来的最终变化。

## 新功能

- 新增音频输出设备页面，可查看连接状态、选择可用设备或恢复系统自动选择。
- 新增歌词同步校准，可让歌词提前或延后，并为不同输出设备分别保存调整结果。
- 歌词设置新增“逐字平滑运动”，可按喜好开启，让逐字高亮和文字运动更连贯。
- 桌面歌词支持多行自动适配，可设置最大行数、最小字号，并选择是否开启歌词切换动画。
- 新增“自动检测更新并下载”开关，默认开启，下载完成后可自行确认安装。
- 歌手和专辑页突出显示最常听的一项，进入详情后可直接播放全部并查看收听情况。
- 播放统计重新整理，歌曲、专辑和艺术家排行可进入独立页面查看完整列表。

## 修复

- 改善切换到其他应用或熄屏后，蓝牙耳机、音箱播放断续的问题。
- 减少快速切歌、反复暂停恢复和退出播放器时的异常，播放操作更稳定。
- 改善普通歌词滚动时偶发的卡顿、抖动和轻微位移。
- 修复桌面逐字歌词高亮位置不准的问题，长句和描边显示更协调。
- 改善切歌后封面和歌曲文字颜色更新不及时、被旧颜色打断的问题。
- 修复下拉菜单圆角处出现黑边、选项被弹出面板遮挡的问题。

## 优化

- 慢唱和长拖音时的逐字上浮更舒缓连贯，暂停、拖动后继续播放更自然。
- 收藏悬浮窗支持连续调整歌单勾选，关闭后统一生效，减少编辑时的列表跳动。
- 设置选项改为靠右向下展开的菜单，均衡器保留便于快速选择的预设按钮。
- 主页工具按钮集中收起并保留搜索入口，多选时隐藏和取消隐藏分别操作。
- 手机和平板界面更统一，封面略微放大，播放页歌词最大字号提高至60。
- 浅色主页采用纯白底色，深浅模式的歌曲主题配色保持一致。
- 动态背景保留柔和扩散的流动感，颜色更鲜明，切歌时背景和歌曲文字换色更顺畅。
- 移除播放页封面外发光，主题配置、统计和歌单的背景样式更统一。
- 撤销切歌时的音色柔化和音效自动降低整体音量，保留用户设置的音色与音量。
