# Android 398：普通歌词滚动绘制与真机复测

日期：2026-10-16。版本 `1.0.0+398`，正式 ARM64 versionCode `2398`。本轮针对“关闭逐字后，歌词滚动启动及落位仍卡顿”继续修复。用户已允许系统安装确认，且此前明确有真机连接即默认允许相关测试。

## 结果与原因

397 已移除滚动边界的逐行 Widget 重建，但真机仍能复现普通歌词开始滚动时的绘制尖峰。白色文字透明度交接会更新原生段落，行缩放也会让模糊光晕重新生成绘制结果。仅保持 Widget、滤镜层和缓存边界身份不能消除这部分成本。

398 将符合条件的白色文字前景保持为同一个白色段落，只对前景透明度做合成；光晕单独保留原叠加关系。普通/动感模式的较大光晕按完整设备像素密度预先绘制为图像，滚动时复用，减少重复生成模糊光晕。32/40 字号组件的启动附近绘制 P95 从 56.114/45.196ms 降到 14.816/18.711ms；落位附近约 6～7ms。

仍有首次加载与部分大字帧超时；弹性对照未见改善，不能据此宣称全部模式零卡顿。

## 实现与成本边界

- `lyric_plain_foreground.dart`：仅当普通歌词基础色和高亮色均为白色时使用固定白色段落与独立透明度。装饰、阴影、前景/背景 Paint、彩色 emoji 等保留原生文字路径；白掩膜装饰色保持稳定，避免无关颜色插值重新塑形。光晕不与文字一起放进统一透明度层，避免改变原 source-over 叠加。
- `mobile_lyrics_list.dart`：普通光晕仅在没有弹性作用域、半径至少 6、无文字装饰、DPR 1～4、图像各边不超过 4096、单图不超过 2M RGBA 像素时缓存。按原生 DPR 绘制，不降采样。原光晕强度、颜色与布局不变。
- 所有普通光晕图像及待完成任务共享 8M 像素预算，约 32MiB；超限继续绘制原矢量光晕，不等待、不隐藏歌词。预算包含已请求但尚未完成的任务，销毁/失败后正确释放。这是额外缓存预算，不是进程 RSS、全部 GPU 缓存或显存总上限。
- 资源准备复用既有空闲调度，不新增逐帧时钟或逐帧图像生成。几何、颜色、DPR 改变会失效；过小/过大光晕走原路径。现有中文物理折行弹性路径及其原图集参数保持。
- `lyric_elastic_rows.dart` 的图片容器增加可配置的整段绘制、边距及预算/释放回调；旧弹性路径默认值保持。图像采样复用 Paint 和已准备的矩形，避免绘制时反复分配。

原跟随轨迹、弹簧、620ms 焦点交接、透明度/模糊/光晕参数、7% 逐字上浮、媒体时序和音频均未调整。背景保持 394；没有新增设置或说明注释。保留正式数据，不卸载、不清空。

曾测试但未采用：仅缓存前景、移除重复缓存边界，均未解决主要绘制尖峰；低分辨率光晕虽变快但像素质量不合格。对应失败、源码及 APK 留在外部证据目录，生产未采用这些删层或降分辨率改动。
