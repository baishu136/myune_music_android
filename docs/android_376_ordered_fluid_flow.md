# Android 376：舒缓开放色带

日期：2026-10-10（Asia/Shanghai）。版本 `1.0.0+376`，正式ARM64 versionCode2376。

## 结果与设计

用户要求重做动态背景，色彩衔接缓和，多色块不挤压、不包裹，观感美观耐看。375虽改成两侧相邻色域，仍由椭圆覆盖驱动，容易表现为巨大色团，交界处也可能过于集中。本轮改成沿纵向舒缓弯曲的三个开放色域，没有独立圆形中心、径向环带或色团叠层。

- 主色、辅助环境色、副色依次沿横向衔接。两条交界共享同一波形中心，间距在屏幕宽度31.5%–36.5%内变化；每条交界使用40%宽度的五次平滑包络，避免细窄硬接缝。
- 中心线只依赖纵坐标和时间，横坐标保持单调。混合权重为 `1-leftJoin`、`leftJoin-rightJoin`、`rightJoin`，非负且和为1；三个几何色域始终保持次序，贯通上下边缘，无法形成闭合包裹。颜色相近的封面自然可能合并观感，不人为造出互补色。
- 中间色保留真实环境色58%的局部贡献，其余来自主/副色，宽渐变中的过渡仍可能降饱和度。没有加光或白色洗亮，主副色保持辨识度。
- 沿色带加入长波明暗流动，地色与颜料的覆盖比例55%–85%，没有满强度的实色圆核。亮暗随同一连续相位缓慢变化，纯黑保持黑、单色不新增色相。
- 保留375的41.89秒周期、两组不同谐波连续变速、实例随机初相位及快照续接。运动是周期伪随机，并非每帧随机；新版主要靠色带舒展及光感移动，不用强烈旋转/碰撞制造流动感。

实际运行行为只修改 `shaders/fluid_background.frag`；模型修改为角色注释，另同步版本、应用更新记录和测试。48-float uniform ABI、650ms切歌调色板过渡、质量调度、FFT幅度响应、后台/路由/减少动画保护及单次CustomPainter绘制保持。375封面淡入与歌词时钟、静止绘制优化、374高斯、7%上浮及主页/歌曲选择均逐文件保留。没有增加纹理、图片生成、模糊层或逐帧Widget构建。
