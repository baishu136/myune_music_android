# Android 377：封面颜色跨度与三色块环绕

日期2026-10-10（Asia/Shanghai）。`1.0.0+377`，正式ARM64 versionCode2377。

## 实现

用户要求封面背景过渡时长按颜色跨度决定，动态背景取消固定彩虹排布，三个色块绕屏幕中心不规则运动、持续变速及变色。377覆盖376的开放色带设计。

封面背景：`CustomThemeBackground`在封面模式启用共享GaussianArtworkSurface的自适应淡入。已解码纹理一次性缩采样16×16，比较新旧RGBA的加权均方颜色差，平滑映射到280–900ms，近色更快、跨色更慢。采样读取预乘RGBA，透明度只计算一次。全图采样是颜色跨度的近似，空间配色变化也影响跨度；没有引入完整原图读回或逐帧取色。新图及采样准备好之前保持上一张图，首张图立即显示；读取失败回退调用方450ms，系统减少动画直接交接。

每次交接固定自身时长，普通重建不重新改时长/启动采样；异步完成检查挂载与图像修订号，销毁后不启动动画。最多两张图绘制，另保留一个最新待切目标。连续跨色快速切歌可能经过两次过渡，最新目标到完整显示最多约1.8秒，另外还需解码/采样时间。原生高斯、完整纹理、镜像边缘、屏幕外支持、稳定滤镜/图像及前景结构保持；自定义文件仍不新增此过渡。这里调整封面新旧图片交接；流体切歌配色650ms和原有路由/Hero时长保持。

动态背景：三种真实封面颜料采用相隔120°的基础轨道，各自有受限的角度和半径谐波扰动。半径.205–.315屏幕归一化单位，纵向系数1.08；公共平滑变速叠加各自速度变化，基础角间距与扰动限幅使中心保持距离。共享相位继续使用可见、非阻塞实际时间，完整周期41.89秒，实例随机起点、快照续接、不同质量调度和后台/路由保护保持；运动为连续周期伪随机，不每帧抽随机数。

三场采用相同径向衰减 `1/(1+d²)`的三次幂，并归一化成非负且和为1的混色权重。它替换376有序交界，不恢复旧Screen加光或指数Power-Softmax。较弱的平滑域扭曲使交界舒展，没有环形蒙版/分层覆盖。主色second、真实环境色third和副色fourth均为色块颜料；每一色块持续借入相邻真实颜料3%–13%，使用不同时间谐波，避免固定颜料平台或硬换色，不额外生成彩虹色相。覆盖.66–.82并沿纵向缓慢流动；纯黑保持黑，单色只在既有颜色及明暗之间变化。归一化混色和互补色交界仍可能降彩，不保证所有像素零灰。

48-float ABI、取色worker/缓存、单次shader绘制、FFT平滑空间响应保持。歌曲逻辑、歌词7%上浮、静止歌词重绘与启动旧样本过滤、主页架构和歌曲选择均相对376逐文件保留。
