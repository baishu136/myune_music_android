# Android 374：一致的封面高斯背景、边缘采样与7%逐字上浮

日期：2026-10-08（Asia/Shanghai）。版本 `1.0.0+374`，显示 `1.0.0-android.374`；正式 ARM64 versionCode2374。承接用户未完成的封面背景请求，并纳入最新的“逐字上浮7%”“移除主页禁用主题色底部注释”。361–373的功能、源码与历史留档全部保留；没有Git提交/推送/Release。

## 原因与复现

373静态图片背景先显示原生 `ImageFilter.blur`，空闲CPU任务完成后改用低分辨率预模糊PNG并关闭原生滤镜。两边的高斯参数并不等价：CPU请求半径使用屏幕sigma的缩放值再乘.80，而本地 `image-4.9.2` 实际标准差为半径的2/3、核截断在±半径（1.5标准差）。不计取整/半径上限/其他缩放时，换算回屏幕约为原sigma的.533倍。两套算法都是高斯核，不能将其描述为高斯变成盒式模糊；用户看到的是延迟替换后的强度、核支持和采样差异。

CPU路径先双线性缩小，再裁剪，再模糊。周期3像素的细条纹缩成1/3尺寸时会取到固定相位，原本85的平均亮度变为255；后续模糊无法恢复已丢失的频率信息。裁剪提前移除屏幕外纹理，边缘卷积也无法再使用真实原图信息。

`F:/AGENT/1/test-artifacts/cover-gaussian-374/red_cases.dart` 在修改前373运行，三个样本均失败：条纹平均亮度、裁剪外红色墨迹参与卷积、空闲结束后原生滤镜仍启用。原定义依赖已移除的CPU接口，因此保留为旧实现复现记录；新实现使用独立的原生像素回归，不把旧定义描述成原样转绿。

## 实施

- 新增 `GaussianArtworkSurface`：整个图像生命周期使用原生高斯滤镜，不再在播放一段时间后改用CPU预模糊PNG。移除旧worker、预模糊LRU、空闲发布和相关调试接口。
- 原图使用 `ImageShader` 的镜像纹理和 `FilterQuality.medium` 缩小采样，保持中心cover比例；不生成低分辨率双线性中间位图。先在屏幕外绘制3倍显示sigma的纹理支持，再卷积，最后裁剪视口。镜像的是原图边界，不是预先裁剪的屏幕边缘；避免拉长最边缘的单列像素。
- 保持强度0–40映射sigma0–90和原1–1.20取景缩放；实际显示sigma为原sigma乘取景缩放。透明度、深浅色遮罩、自定义图片/封面优先级保持。共享静态图片背景中的封面与自定义图片都走新表面；流体shader未修改。
- `Image`与滤镜祖先持续挂载，内容相同的封面字节沿用缓存键，前景切换不重建原图纹理。shader/滤镜按图像、视口、强度复用，shader在替换/销毁时释放；原图由Flutter图像流持有。静态背景保留RepaintBoundary。
- Mini Player现有空闲资源准备增加当前歌曲静态背景的 `MemoryImage` 预解码；与实际背景使用同一缓存键，异步等待不长期占用UI空闲许可。仅尽力预热当前曲，不额外固定一份完整图像。原目标尺寸封面预解码仍保留；流体切回静态的预解码也同步改为 `MemoryImage`。
- 逐字默认上浮基准由9%改为实际文字行高7%，保留760ms媒体时间、flowingTop、跟随和快字10%短暂超调，瞬时峰值可到7.7%。内部可配置上限仍为9%。普通歌词继续只高亮正播行。
- 仅删除“主页禁用主题色”的subtitle，开关本身和持久化功能保持。
