# Android 257：流体背景颜色流动与暗色取色优化

日期：2026-09-11

## 问题定位

- 原控制器每完成一个基础运动周期便在 `2π` 处重置相位。
- Shader 的运动频率包含 0.27、0.47、0.61、0.73 等非整数谐波，这些波形在 `2π` 两端数值不同，因此每约 18.5 至 26 秒会让多个色团瞬间换位，表现为突然色块闪烁。
- 原取色会丢弃亮度低于 0.06 的所有像素，暗色封面容易失去真实代表色并回退到主题色。

## 改动

- 相位改在所有百分制谐波均连续的 `200π` 共同周期处循环；在当前档位下约 31 至 43 分钟才循环一次，循环边界仍保持连续。
- Shader 使用两层低频坐标流动，降低单层扭曲幅度，扩大色团半径并加入很小的权重底值，让相邻颜色始终柔和参与混合。
- 色团数量仍为 4，刷新率和三个质量档位均未提高，避免用额外绘制负担换取视觉效果。
- 暗色取色仅过滤极暗且近中性的无信息像素；具有色相的阴影会保留，并将亮度温和提升到适合背景显示的范围。
- 色板过渡由 900 毫秒延长至 1100 毫秒；相同色板不再重复启动插值。
- 256 版的 620 毫秒播放页入场以及流体色板、相位连续性缓存保持不变。
