# Android 0.9.9+282 播放定时与逐字歌词

## 改动

- 播放定时新增“延时到整首播完后结束”。开启后计时归零不会立刻暂停，而是等待当前歌曲自然结束；等待期间取消无缝播放的下一首预载，结束后不再自动续播。
- 计时等待状态会显示“计时已结束，将在当前歌曲播放完后停止”，仍可取消；定时进行中切换该开关会立即同步淡出策略。
- 歌词设置新增逐字歌词总开关，以及“仅适配”和“全部”两种范围。
- “仅适配”只渲染带有效逐字时长的 LRC；“全部”会为普通歌词按相邻行间隔的 92% 生成时间轴，单行时长限制为 650—8000 毫秒。
- 当前字符采用连续颜色插值，减少逐字边界跳变；播放位置仍只刷新当前歌词行，不触发整个列表重建。
