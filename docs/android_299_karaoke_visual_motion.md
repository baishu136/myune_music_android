# Android 0.9.9+299：逐字歌词完整视觉修正

## 视频对比结论

- 298 的三次缓出曲线在词元前半段过快完成大部分上浮，随后变化很小，呈现“突然跳起后粘住”的观感。
- 单份字形渲染不再保留灰色基线副本后，原有 12% 字高的抬升显得过强，播放与未播放部分之间形成明显阶梯。
- 每个词按自身选择框高度计算位移，大小写、升部和降部不同的字形会产生不同终点，并在切换到已完成组合层时轻微跳动。
- 高亮前沿偏窄，部分帧的灰白交界比参照视频更硬。

## 实现

- 上浮改为 smoothstep S 型曲线，起点和终点速度都平滑归零，中段持续运动。
- 上浮幅度改为统一排版行高的 8%，限制在 1.5—6 像素；当前词和已完成词共用同一个位移基准。
- 羽化宽度改为字框宽度的 16%，限制在 4.5—12 像素，使颜色推进更柔和，同时保持播放侧完全高亮。
- 保留单份字形分段渲染：活动词只绘制一次，再通过 `srcATop` 在字形像素内着色；无法映射的文本继续静态显示。
- 保留 296 的行级进退位移、620 毫秒切行节奏、跳转即时同步、视觉时钟平滑和后续全部功能。

## 性能与回归保护

- 播放进度仍只触发当前 `CustomPainter` 重绘，不重建或重新布局歌词列表。
- 文本布局、词框、已完成组合层、候场组合层和活动词排版继续缓存。
- 测试覆盖曲线四分位点、首尾平滑、羽化边界、绘制器单实例更新、跳转与完整歌词滚动行为。
