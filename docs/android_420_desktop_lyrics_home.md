# 420 主页封面与桌面逐字歌词

2026-10-24，1.0.0+420，ARM64 versionCode 2420。基于完整419工作区修改，保留419自动更新等尚未提交成果，本轮不提交、推送或发布GitHub Release。软件内日志保持最后实际发布的412。

## 修改

- 主页歌曲列表封面增加10%：普通48→52.8dp，歌单分栏40→44dp。普通行最小高度仍为67dp，扩大系统字体时允许自然增高。未改变播放页大封面、专辑/歌手详情大图或索引网格的自适应尺寸。
- 正播歌曲标题、歌手/专辑副标签及索引模式歌曲名使用实际主题主色。关闭主页主题色时仍仅为正播标签保留该颜色，其余条目保持原样。切歌只重建新、旧正播标签，其他条目的文字组件保持；暂停仍标识当前歌曲。
- 桌面歌词旧实现将Android字符选择路径直接取外接矩形。选择范围刚好结束于折行边界时，Android还包含相邻行的空白首尾，矩形因而跨行；省略部分也可能生成高亮区域。现在按实际物理行范围裁切，只保留可见文字，并保留被省略文字应占的词元时间。
- Android 29及以上硬件绘制时，将原色文字/描边和高亮文字分别录制并复用；逐帧仅更新高亮裁切路径，字体、文字、宽度、对齐或颜色变化才更新绘制记录。旧系统/软件Canvas继续直接绘制。未新增整屏位图缓存。
- 每800ms校时改为只发送时钟和播放状态，跳过重复歌词合成、词元解析、完整样式应用及播放按钮等控件更新。空拍期间仅预约下一可见字开始时的重绘；唱完、暂停、隐藏和移除窗口时停止逐帧调度，恢复时重新定位。
