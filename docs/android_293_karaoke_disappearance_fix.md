# Android 293：逐字歌词消失修复

日期：2026-09-14

## 问题确认

- 实机视频显示，Android 292 播放逐字歌词时，已完成文字及当前行的大部分内容会被清空，只剩正在扫过的局部文字。
- 原因是 292 为去除基线重影引入的 `BlendMode.clear` 嵌套合成层在设备 GPU 上扩大了清除范围。

## 修改

- 完全移除逐字歌词路径中的清除混合层。
- 基线文本改为在词元完成时生成并缓存“隐藏已完成词”的排版层。
- 已完成词继续在独立高亮层中保持上浮；当前词继续沿用 291 的逐字上浮动画。
- 保留 291 的歌词行入场、离场位移、持续时间、上浮曲线和幅度。
- 保留跨行词元完成片段的最终上浮位置及最大上浮安全区修正。

## 性能

- 基线排版只在一个词完成时更新，不随每个动画帧重新布局。
- 每帧继续复用基线、当前词、已完成词和字框缓存，不增加 Widget 或 Ticker。

## 验证

- 执行 Dart 格式化、Flutter 静态分析、歌词专项测试及完整测试。
- 构建并校验 arm64-v8a release APK，设备可见时自动覆盖安装，并留档源码和构建产物。
