# 341：恢复歌词拉开换行、统一逐字非焦点行、歌曲间距均值与封面淡入

2026-10-02。以实际工作区 0.9.9+340 为基线，递增至 0.9.9+341 / 0.9.9-android.341。已阅读 README、相关源码及测试、287/295/332/337/338/340 记录，并对照保存的 338 源码；适用目录未发现 AGENTS.md。保留大量已有未提交和未跟踪成果，不进行整库回退。

## 查明的问题与修改

### 1. 恢复原换行的上下拉开效果

339 为统一滚动驱动，将 `_withLineShift` 中原有 AnimatedSlide 改成了无位移 KeyedSubtree。于是普通模式也失去焦点附近上方 `-.16`、下方 `+.22` 的相对行高位移。这是本轮用户指出的默认动画变化，不是逐字时间轴问题。

- 恢复原相对偏移、420ms 和 `mobileLyricsFocusTransitionCurve`。普通/逐字共用相同的 LyricPhaseSlide 元素，不因逐字开关替换节点或重置姿态。
- LyricPhaseSlide 沿用既有相位保持逻辑；密集换行从当前呈现偏移继续，duration/curve 改变前采样旧曲线。显式 seek 使用零时长立即定位，普通换行再恢复原有时长。
- 这是有意恢复的焦点间隙效果，不再要求所有绘制行间距绝对刚性。整列表/弹性选项仍保留 340 共用的驱动及连续速度；没有重新启用另一套逐字专用滚动模型。
- 只使用合成层 SlideTransition，不更改 item 高度、折行布局或实际词元高亮边界。保留有界预热、字形蒙版修复、共享帧时钟和模糊结果缓存。
- 手动浏览继续将局部位移目标置零；间奏 240ms 独立退出及正文居中接力保留。

### 2. 逐字模式统一非高亮行的字体/显示目标

340 的 TextStyle 本身已经使用相同字号、字重和基础色，但外层透明度仍按 `.68/.52/.40/.32` 的距离阶梯变化，景深也按距离不同。因此仅比较 TextStyle 无法保证可见一致性。

- 非焦点原文统一字体、字号、字重、行高 1.2、基础色、scale=1 目标。深色/亮背景处理使用白色及 .36 的统一透明度，浅色无背景使用 #757575 及 .68。
- 若用户开启歌词行模糊，所有非焦点正文使用同一个缓存 sigma=.9；关闭时仍没有滤镜。普通模式的距离透明度/模糊阶梯不变。
- 翻译/罗马音统一在原文弱化程度基础上乘 .6，保持静态、不做逐字运动。未带真实时序而使用“仅适配”模式的静态行也采用相同翻译规则，不再因为绘制路径不同而显示强度不同。
- 已失焦的上一行仍平滑完成原有焦点缩放/透明度交接，短暂保留交接姿态；不为了瞬时参数一致而硬切字号或亮度。间奏圆点退出为独立状态，不当成正文文字。
- 字形高亮时间、估算配速、上浮高度/时长和播放器同步没有修改。透明度仅合成一次，不通过字形颜色与外层 alpha 重复衰减。

### 3. 歌曲间距取旧版与紧凑版均值

337 记录与旧版布局测量：原普通行 78dp / 48dp 封面之间留 30dp；紧凑版普通行 56dp / 封面间留 8dp。均值为 **67dp 行高、19dp 封面间距**。

- 普通列表使用 67dp 的 ListTile 目标行高，取消该 tile 外侧额外的 2dp 上下 contentPadding，避免实际行高变成 71dp。保留内部最小垂直边距、48dp 封面和点击区域。
- 手机/小平板的封面预取估算共用 67dp。大系统字体可自然增高，不强行固定高度裁切文字。
- 网格及歌单分栏原有布局参数保持不变。

### 4. 封面页切歌新增 320ms 淡入

- 正在显示封面且路由转场已经结束时，新图**实际解码完成**后采用 easeInOutCubic 淡入；原图保持在下面，避免两张图同时降低 alpha 造成中途变暗。布局、圆角和封面尺寸固定，不叠加放大、旋转等效果。
- 仍由同一个 Image 元素监听当前数据源和保持 gaplessPlayback；不以 provider key 变化为开始时间，异步等待时保留旧解码帧，迟到旧来源不能覆盖新来源。
- 解码帧使用 ui.Image.clone 保留句柄；至多两张显示帧和一张最新待切帧。连切时让已呈现的混合自然完成，再只接续最新待切封面，避免丢弃上一层而跳闪。多次连切可能让最新封面最多等待一个 320ms 淡入周期，这是本轮连续性优先的取舍。
- 动画完成、待切替换、明确无封面和组件销毁均释放持有句柄。测试实际检查退出/销毁后的 debugDisposed，不只检查 Widget 数量。
- 歌词页、进出播放页 Hero 飞行或系统减少动画时不运行动画；关闭时立即保留最新解码结果。保持图像语义和系统颜色反转处理。明确无封面仍显示原占位，不长期借用上一曲封面；解码失败继续走原有回退机制。
- 动画帧仅更新 FadeTransition 合成层，不重复取封面来源、解码、排版或全页 setState；只在换图/完成时更新局部状态。
