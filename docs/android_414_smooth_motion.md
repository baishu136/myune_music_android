# Android 414：逐字平滑运动、背景传色及原始音色

播放页歌词设置的“逐字歌词”开启后，可选择“逐字平滑运动”。默认关闭，保存后重启保持。开启时：

- 相邻、同物理行、同方向且时间连续的真实逐字片段接入单调三次曲线，节点保持原开始/结束时间，速度连续而不越界；原合成逐字沿用已有连续前沿。真实停顿、重叠或倒序时间、换行及文字方向变化不串接，不把估算称为真实演唱时间。
- 字形上浮采用起止速度与加速度均为零的五次曲线，保持7%排版行高与760ms媒体时长，保留有限相邻牵引，取消快字10%额外回弹。退出及原行滚动模式保持；关闭新开关时走原算法。
- 小幅媒体校时使用120ms速度响应、积分求视觉推进，校正幅度限制在正常速度±8%；暂停不漂移，显式seek即时定位，倍速同步。不是延迟整首歌词或补掉真实停顿。
- 平滑模式保持冷/热缓存的同一排版几何前沿，避免图像就绪后切换到另一套字缘路径。开关写入预热缓存身份，代次变化撤销旧任务；每帧只更新原缓存与画布，未新增逐字Ticker、Timer、排版或制图。无回弹时可以更早停止额外位移绘制。正常模式原像素门槛未放宽。

背景变色速度为413的40%，仍平缓加减速。四色团共享至少8个不同的封面相关候选色，纯黑等纯色例外；只在取色阶段补齐及按邻近颜色安排访问顺序，避免跨互补色直接往返造成大面积偏灰，没有提高饱和度或增加鲜艳色对比度。既有切歌中间色及重定向连续性保持。

扩大中心漂移和径向游走，使色团能跨越可见中心并移出屏幕。四个核心保留有界形变，最大直径不超过屏幕长边的2/3。20个稳定伪随机传播事件与五圈整体周期同步，随机选择起始团及传播方向；邻近边缘接触时才增加传色。主要传色在Shader交叠处出现，核心只缓慢借入少量颜色；传播同时触发小幅保面积不规则伸缩。边界衰减更柔和，仍是非负凸混色、固定覆盖、无叠加泛白。

Uniform由45扩至49个float，只增加4个边缘传播系数；CPU复用数组、GPU同一个绘制通道，无新增纹理或离屏层。取色与候选排序不进动画帧。扩大游走后同一团在屏幕边缘可能裁成两小段；测试仍检查内部独立色斑，只将同一边界外相连的裁切片段合并，并新增内部双岛反例。未以删色或降低画质门槛取得通过。
