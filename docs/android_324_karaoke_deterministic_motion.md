# 324：逐字歌词确定性动效

## 问题与方案

- 323 版局部节奏只调节五级预上浮；主上浮仍被下一字符起亮时到顶的约束压缩，且两段位移合成可能产生“微抬—停顿—再抬”。正常换行后，失焦旧行的媒体时间被重设为行首附近，造成姿态回落。
- 默认动效现由 `KaraokeGlyphTiming` 与 `karaokeGlyphFrame` 根据媒体时间直接计算。同一时间、歌词时间与配置总得到同一高亮和位移。高亮沿用 323 版词元边界、视觉补偿和词元内部字素估算；估算并非真实逐字时间。位移单独以媒体时间推进，不再由下一字高亮时点或五级接力限制终点。
- `KaraokeMediaClock` 接收实际播放倍率、输出状态、普通位置修正及明确 seek；滚动弹簧不参与逐字位移。正常换行将旧行时间冻结，再用单独退出动画使位移归零；明确 seek、手动浏览和切歌不使用该退出过程。
- 排版阶段缓存字素几何、词元关系、时间映射和绘制缓冲区；普通绘制帧只消费媒体时间与缓存。复杂字符仍整词回退，保持单次透明度遮罩、高亮颜色和折行布局。仅保留一个内部常量开关用于本版新旧对照，不增加公开设置。

## 默认参数

上浮高度为字号行高的 4.5%，并限于 1.2–4.0 px；上浮时长 760 ms **媒体时间**；顶部缓冲为平滑缓出；局部错开为估算字符节奏的 15%，最多提前 35 ms；高亮渐变宽度系数 0.72；正常换行退出 240 ms 实际时间。配置参数在构造时校验范围。0.75/1/1.5/2 倍速下，上浮消耗的媒体时间相同，实际观看时长按倍率变化。
