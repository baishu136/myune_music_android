# Android 292：逐字上升合成修正

日期：2026-09-14

## 对比结论

- 最新 Myune 视频中，高亮文字上浮后原基线仍保留灰色副本，视觉上形成双层字形和拖影。
- 参照视频中，已播放部分会干净地离开基线；已完成词保持抬起，未播放部分继续停留在原基线。
- 跨行词元的已完成片段在现版中会被重新绘制到基线，且上浮安全区没有按最大位移预留。

## 修改

- 将正在播放的一行限制在独立的小型合成层内，仅清除已播放字形在基线上的像素，不影响动态背景和相邻歌词。
- 已完成词整体清除基线副本；当前词只按高亮进度清除对应区域，未播放部分保持原样。
- 跨行词元的已完成字框继续使用最终上浮位置，不再落回基线。
- 上浮绘制区域按完整动画的最大位移预留，避免大字体或靠近顶部时裁切字形。

## 性能

- 合成层范围只覆盖当前歌词行，不扩展到整个歌词页或动态背景。
- 继续复用文字布局、词框、当前词和已完成词缓存；逐帧不新增文字测量或 Widget。

## 验证

- 执行 Dart 格式化、Flutter 静态分析、歌词专项测试及完整测试。
- 构建并校验 arm64-v8a release APK，随后连机安装（设备可用时）并留档源码与产物。
